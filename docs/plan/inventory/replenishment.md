# 补货与预测 PRD

> 覆盖页面：`web-admin/app/pages/inventory/replenishment.vue`、与采购、渠道上架、旅程中的补货任务有关的组件。该模块负责安全库存策略、需求预测、补货建议、审批、与采购单联动。

## 1. 背景与目标
- 现有页面仅展示静态补货建议，需要基于真实库存、销售预测、促销计划提供自动化补货与安全库存管理。

**目标**
1. 定义安全库存策略（按 SKU/渠道/仓库），结合历史销售、季节性、活动，生成补货建议。
2. 支持手动/自动生成采购单或调拨单，提供审批、任务、异常处理。
3. 提供预测模型、参数可配置、结果可解释，支持多种预测源（统计、AI、外部系统）。

## 2. 信息架构
1. **补货看板**
   - 指标：建议补货数量、缺货风险 SKU、补货完成率、安全库存达成率、在途补货。
   - 筛选：仓库、渠道、SKU、供应商、风险等级、活动。
2. **补货列表**
   - 字段：SKU、仓库/渠道、安全库存、当前可售、在途、预测销量、建议补货量、建议到货时间、供应商、状态（草稿/审批/执行/完成）。
   - 操作：查看、编辑、生成采购单/调拨、提交审批。
3. **补货详情**
   - 基本信息：SKU、仓库、渠道、供应商、预测模型、参数、计算过程、建议。
   - 决策跟踪：审批记录、责任人、执行任务、到货跟踪、差异分析。
   - 关联：采购单、调拨单、促销计划、营销活动、旅程。

## 3. 功能清单
| 功能 | 描述 |
| --- | --- |
| 安全库存策略 | 按 SKU/仓库/渠道设置安全库存（静态/动态）、覆盖天数、算法参数 |
| 预测模型 | 支持多种模型（移动平均、季节性、ARIMA、AI）、可配置参数、模型评估 |
| 补货建议 | 根据当前库存、在途、预测销量输出建议；支持人工调整、注释 |
| 采购/调拨联动 | 一键生成采购单、调拨单、任务；同步到采购模块 |
| 审批流程 | 大额/关键 SKU 补货需审批；记录理由、版本 |
| 任务跟踪 | 将补货执行任务分配给采购/仓库，跟踪到货、入库、差异 |
| 告警 | 安全库存不足、预测异常、供应商无法交货时告警 |
| 日志/历史 | 记录每次建议、执行结果、偏差，供优化模型 |

## 4. 流程
1. **策略配置**：设置安全库存 & 模型参数 → 保存。
2. **生成建议**：系统每日/实时计算 → 生成补货建议 → 通知责任人。
3. **审批/执行**：责任人审核建议 → 调整 → 提交审批 → 生成采购/调拨单 → 执行。
4. **反馈/优化**: 到货后记录实际 vs 建议差异，优化模型参数。

## 5. 数据 & API
- 表：`replenishment_policies`、`replenishment_forecasts`、`replenishment_suggestions`、`replenishment_tasks`、`replenishment_logs`。
- API：`GET/POST /api/inventory/replenishment/policies`、`GET /api/inventory/replenishment/suggestions`、`POST /api/inventory/replenishment/suggestions/{id}/approve`、`POST /api/inventory/replenishment/suggestions/{id}/generate-po`。

## 6. 权限 & 审计
- 权限：`replenishment.read`、`replenishment.manage`、`replenishment.approve`、`replenishment.tasks`。
- 审计：策略变更、建议调整、审批、执行记录，带 diff 与备注。

## 7. KPI
| 指标 | 目标 |
| --- | --- |
| 安全库存达成率 | ≥ 95% |
| 缺货率 | < 2% |
| 预测偏差（MAPE） | < 10% |
| 补货响应时间 | < 24h |

## 8. 风险
- 数据质量影响预测；需要数据校验与回溯。
- 模型复杂度高，需可解释性与人工调整。
- 供应商/采购系统对接不畅，需 API 与任务跟踪。

## 9. Backlog
- AI 自动调参与策略推荐。
- 与供应商 Portal 联动，实时确认生产能力。
- 与营销活动联动，提前锁定库存。
- 全链路模拟（假设分析）。
