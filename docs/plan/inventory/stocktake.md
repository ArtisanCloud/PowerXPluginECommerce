# 盘点与任务 PRD

> 覆盖页面：`web-admin/app/pages/inventory/stocktake.vue` 以及计划中的盘点任务、移动端、差异分析组件。此模块负责盘点计划、执行、差异处理、审计、任务协同，与库存、仓库、财务、售后联动。

## 1. 背景与目标
- 当前盘点页面仅展示示例，需要支持不同盘点类型（全盘、循环、抽检）、任务派发、移动端扫描、差异分析和审计。

**目标**
1. 盘点计划：配置范围、仓库/库区、SKU、时间、人员、工具、审批。
2. 盘点执行：移动端/手持扫描、离线支持、实时上传、异常记录。
3. 差异处理：自动对比系统库存，生成差异单，支持审批、原因分析、自动调账（关联财务）。

## 2. 角色
| 角色 | 诉求 |
| --- | --- |
| 仓库管理 | 制定计划、分配任务、查看进度 |
| 盘点员 | 获取任务、扫描盘点、提交异常 |
| 财务 | 审核差异、调账 |
| 供应链主管 | 监控盘点健康、审计日志 |

## 3. 信息架构
1. **盘点计划列表**
   - 字段：计划名称、类型（全盘/循环/抽检）、仓库、SKU 数量、状态、负责人、开始/结束时间、结果。
   - 操作：查看、编辑、复制、取消、生成报告。
2. **盘点详情**
   - 基本信息、范围、参与人员、工具（手持、移动 App）、审批记录。
   - 任务列表：任务编号、库区/SKU、指派人、进度、异常。
   - 实时进度：已完成百分比、发现差异、阻塞。
   - 差异分析：SKU、系统数量、实盘数量、差异、原因（损耗、捡错、供应商错发）、处理状态。
   - 报告 & 审计：结果摘要、调账单、附件、签名。
3. **移动端/扫描视图**（设计说明）
   - 扫码录入 SKU、数量、批次；支持离线缓存、同步；可附加照片、备注。

## 4. 功能清单
| 功能 | 描述 |
| --- | --- |
| 计划创建 & 审批 | 配置范围、周期、模板；审批（仓库主管/财务） |
| 任务派发 | 自动拆分任务按库区/SKU/人员；支持手动调整、SLA |
| 扫描录入 | 移动端/App/手持设备扫码，离线缓存、批量导入 |
| 异常记录 | 损坏、缺失、条码异常、库存锁定冲突；生成任务 |
| 差异分析 | 自动对比，生成差异单，提供原因分类、照片、备注 |
| 调账 & 审计 | 差异确认后生成调账单，触发库存调整、财务凭证 |
| 报告 | 导出盘点报告、签名、历史对比；支持 KPI 分析 |

## 5. 流程
1. 计划→审批→生成任务→盘点员执行→提交数据。
2. 系统实时更新进度、告警；仓库主管复核。
3. 差异审核→生成调账→更新库存/财务→关闭计划。

## 6. 数据 & API
- 表：`stocktake_plans`、`stocktake_tasks`、`stocktake_entries`、`stocktake_diffs`、`stocktake_logs`、`stocktake_reports`。
- API：`GET/POST /api/stocktake/plans`、`POST /api/stocktake/plans/{id}/tasks`、`POST /api/stocktake/tasks/{id}/submit`、`POST /api/stocktake/diffs/{id}/approve`。

## 7. 权限 & 审计
- 权限：`stocktake.read`、`stocktake.manage`、`stocktake.task`、`stocktake.diff`、`stocktake.report`。
- 审计：计划变更、任务、差异处理、调账记录；需支持签名/照片附件。

## 8. KPI
| 指标 | 目标 |
| --- | --- |
| 盘点完成率 | ≥ 95% |
| 差异率 | < 1%（视品类） |
| 处理时效 | 差异 48h 内完成 |
| 审计合规 | 100% 计划有审计记录 |

## 9. 风险
- 数据同步延迟导致差异；需锁定库存或设置黑屏期。
- 手工录入错误；需扫码、照片、二次确认。
- 盘点与运营冲突；需计划与通知。
