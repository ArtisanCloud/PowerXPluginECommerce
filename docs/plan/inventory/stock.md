# 库存视图 & 库存状态 PRD

> 覆盖页面：`web-admin/app/pages/inventory/stock.vue`，并在商品详情、渠道上架、订单、售后等场景提供库存组件。该模块用于提供统一的库存总览、状态视图（可用、锁定、在途、预留、损耗）、告警与数据接口。

## 1. 背景与目标
- 当前库存页面仅显示示例数据，缺乏实时多维视图、锁定/释放逻辑、批次追踪、告警。需要一个统一的库存之眼，供不同角色查询和操作。

**目标**
1. 展示多维库存视图：按仓库、渠道、SKU、批次、状态（与 OMS/WMS 对齐），支持实时刷新与历史趋势。
2. 支持库存锁定与释放（订单、促销、旅程、售后）、在途跟踪、异常告警。
3. 提供 API 接口供渠道、定价、营销调用，确保数据一致、可追溯。

## 2. 信息架构
1. **库存总览看板**
   - KPI：总库存、可售库存、锁定库存、在途、预留、损耗、周转天数、缺货 SKU、库存健康评分。
   - 筛选：仓库、渠道、SKU/类目、供应商、批次、状态、时间区间。
2. **库存表格/卡片**
   - 列字段：SKU、名称、仓库、渠道、可售、锁定、在途、预留、损耗、批次、有效期、最近变动、告警。
   - 支持 drill-down（点击 SKU → 查看按仓、按渠道、按批次细分）。
3. **库存详情**
   - 库存状态：可售、锁定（订单/促销）、预留（旅程、定金）、在途（采购、调拨）、损耗（损坏、过期）。
   - 批次信息：批次号、生产日期、有效期、供应商、质检状态。
   - 变动日志：来源（订单、补货、调拨、盘点、售后）、数量、操作者、时间、关联单据。
4. **告警面板**
   - 缺货、低库存、超售、高库存、过期、批次异常；可配置阈值、渠道优先级。

## 3. 功能清单
| 功能 | 描述 |
| --- | --- |
| 实时同步 | 与 WMS/OMS/ERP 同步库存变动，具备重试、幂等、延迟指标 |
| 库存状态管理 | 统一定义可售、锁定、在途、预留、损耗等状态及转换规则 |
| 锁定/释放 | 提供 API/事件供订单、促销、旅程锁定/释放库存，并记录来源 |
| 在途跟踪 | 记录采购、调拨、售后返仓在途数量，估算到达时间 |
| 告警 | 缺货、过期、超售、库存失衡等告警，推送任务 |
| 历史与趋势 | 展示库存历史曲线、周转、季节性 |
| 数据导出 & API | 导出 CSV、提供 `GET /api/inventory/stock` 等接口供渠道/营销调用 |
| 权限/视图 | 不同角色看到不同维度，支持自定义视图保存 |

## 4. 流程
1. **库存变动**：来源（订单出库、补货入库、调拨、盘点、售后）→ 更新库存状态 → 写入日志 → 触发订阅/告警。
2. **锁定与释放**：订单/促销/旅程调用锁定接口 → 库存状态从可售转为锁定 → 订单完成后释放或转为出库。
3. **在途监控**：采购/调拨单生成 → 在途数量更新 → 到仓后转为可售/锁定。
4. **告警处理**：触发告警 → 生成任务 → 处理并记录结果。

## 5. 数据 & API
- 表：`inventory_stock`、`inventory_stock_history`、`inventory_batches`、`inventory_locks`、`inventory_alerts`、`inventory_logs`。
- API：
  - `GET /api/inventory/stock`、`GET /api/inventory/stock/:sku`、`POST /api/inventory/lock`、`POST /api/inventory/release`。
  - `GET /api/inventory/batches`、`GET /api/inventory/alerts`、`POST /api/inventory/alerts/{id}/resolve`。

## 6. 权限 & 审计
- 权限：`inventory.stock.read`、`inventory.stock.manage`、`inventory.lock`、`inventory.alerts`。
- 审计：库存状态变更、锁定/释放、告警处理均记录，关联单据（订单、补货、调拨、售后）。

## 7. KPI
| 指标 | 目标 |
| --- | --- |
| 数据延迟 | < 5 分钟 |
| 锁定准确率 | ≥ 99% |
| 告警响应 | < 30 分钟 |
| 库存准确率 | ≥ 98% |

## 8. 风险
- 数据同步延迟或错误导致超售/缺货；需重试、校验。
- 多方锁定/释放冲突；需幂等与冲突策略。
- 批次/有效期信息缺失，影响售后/合规。
