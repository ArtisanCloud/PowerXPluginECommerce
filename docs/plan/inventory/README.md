# 库存与仓储模块规划总览

> 适用范围：`web-admin/app/pages/inventory/**`、`shipping/**`、以及商品、渠道、售后模块中涉及库存/仓储的组件。库存与仓储模块涵盖仓库主数据、库存可视化、补货策略、盘点、调拨、物流、运费模板，与订单、供应链、营销紧密联动。

## 1. 文档目的
- 梳理库存/仓储域已有页面与缺口，明确角色价值与子模块，指导后续 PRD 输出。
- 对齐与商品、渠道、订单、售后、财务的接口，确保库存数据闭环。

## 2. 当前页面覆盖
| 模块 | 前端路径 | 状态摘要 |
| --- | --- | --- |
| 仓库管理 | `inventory/warehouses.vue` | 列表 + 基本信息，缺乏仓库拓扑、权限、容量、KPI |
| 库存总览 | `inventory/stock.vue` | 表格展示库存、锁定、在途，需接入实时数据、告警 |
| 补货与安全库存 | `inventory/replenishment.vue` | 补货建议示例，需接入预测、采购、审批 |
| 盘点 | `inventory/stocktake.vue` | 盘点计划 UI，需移动端、任务、差异分析 |
| 调拨 | `inventory/transfers.vue` | 调拨单列表，需流程、审批、物流、异常处理 |

## 3. 角色与价值
| 角色 | 核心诉求 |
| --- | --- |
| 供应链/仓储主管 | 了解库存健康、仓库容量、调拨、波次、人员负荷 |
| 采购/商品运营 | 获取补货建议、库存周转、SKU 可售情况 |
| 渠道运营 | 确认各渠道/店铺库存、连接上架计划 |
| 客服/售后 | 查看库存、退货入库状态，处理售后/退款 |
| 财务 | 入库/出库成本、库存价值、损耗分析 |

## 4. 功能规划概览
1. **仓库主数据**：仓库/节点、库区/库位、权限、容量、温控、负责人。
2. **库存视图**：多维（仓库、渠道、SKU、批次、状态）查看库存；支持锁定、在途、预留、可用。
3. **补货与预测**：安全库存、补货建议、采购联动、审批、任务。
4. **盘点与任务**：盘点计划、任务派发、移动端扫码、差异处理、审计。
5. **调拨 & 波次**：多仓调拨、审批、物流、批次跟踪、异常处理。
6. **履约与物流**：承运商、运费模板、运单/轨迹、运输任务，与订单、售后、渠道联动。

## 5. 迭代路线
- Phase 1：仓库主数据 + 库存视图 + 基本补货、调拨功能。
- Phase 2：盘点/任务、库存预警、预测、物流模板、运单轨迹。
- Phase 3：高级功能（波次、WMS 集成、自动化预测、AI 建议）。

## 6. 依赖与对齐
- 与商品 SKU、供应商、订单、渠道、售后模块共享数据；库存变动需记录操作日志与审计。
- 需要与采购、财务、物流接口对接（供应商采购单、分账、运费、发票）。

## 7. 下一步
- 为仓库管理、库存视图、补货、安全库存、盘点、调拨、物流/运费等子模块撰写详细 PRD。
- 梳理与订单/售后/渠道的接口（库存锁定、释放、退货入库）。
- 评估与外部 WMS/OMS/物流平台集成方案。
