# 仓库管理 PRD

> 覆盖页面：`web-admin/app/pages/inventory/warehouses.vue` 及后续需新增的仓库详情、库区管理、权限、KPI 视图。该模块是库存系统的主数据入口，负责登记仓库/节点、库区、能力、权限，为库存、调拨、履约提供基础数据。

## 1. 背景与目标
- 目前仓库页面仅展示列表，需要全面记录仓库属性、库区/库位、容量、温控、权限、负责人、KPI，并与渠道/订单/供应链联动。

**目标**
1. 建立仓库主数据：仓库类别（自营、第三方、供应商、门店）、地理位置、能力（冷链、危化）、联系信息、责任人。
2. 支持库区/库位管理，记录容量、温控、SKU 限制，并提供权限控制。
3. 提供仓库 KPI（库存周转、占用率、波次、异常）、任务协同（盘点、调拨、维护）。

## 2. 角色
| 角色 | 诉求 |
| --- | --- |
| 供应链主管 | 总览仓库健康、容量、告警 |
| 仓库经理 | 管理仓库/库区配置、人员、任务 |
| 渠道/商品运营 | 知晓可售仓库、上架策略、库存分布 |
| 财务 | 了解仓库成本、价值、租赁信息 |

## 3. 信息架构
1. **仓库列表**
   - 字段：名称、类型、地区、状态、负责人、容量占用、库存价值、支持渠道、温控、最近同步时间。
   - 筛选：类型、地区、状态、渠道、温控、负责人。
   - 操作：查看详情、启用/停用、同步、创建任务。
2. **仓库详情**
   - 基础信息：地址、联系人、服务时间、租约、费用、证照。
   - 能力 & 限制：温控范围、危化许可、支持的配送方式、支持品类、最大重量/体积。
   - 库区/库位：树状展示库区、通道、库位属性；支持配置容量、SKU 限制、状态。
   - 权限：负责团队、可访问角色、API 凭证（对接 WMS）。
   - KPI：库存周转、占用率、订单履约时效、异常工单、任务列表。
   - 日志：配置变更、任务、审计、异常告警。
3. **库区/库位管理**
   - 列表 + 详情：编号、容量、占用、SKU 限制、温控、状态。
   - 支持批量导入、导出、二维码打印。

## 4. 功能清单
| 功能 | 描述 |
| --- | --- |
| 仓库 CRUD | 创建/编辑/停用仓库，记录详细属性，走审批（如新仓入网） |
| 库区/库位管理 | 添加/编辑库区、库位，配置容量、温控、SKU 限制、权限 |
| 能力标签 | 标记仓库能力（冷链、危化、跨境），供调拨/订单匹配 |
| 渠道绑定 | 绑定可服务的渠道/店铺、SKU、服务 SLA |
| KPI 看板 | 这座仓的库存周转、占用率、波次、异常、任务 |
| 告警 & 任务 | 低容量、温控异常、设备维护提醒，生成任务单 |
| 外部集成 | 支持导入 WMS 数据、同步库存/任务、API 凭证管理 |

## 5. 流程
1. **新增仓库**：提交仓库信息 → 审批（供应链主管、财务）→ 生效 → 绑定渠道/SKU → 初始化数据。
2. **库区配置**：创建库区 → 配置容量、温控、SKU 范围 → 分配权限 → 同步到库存系统。
3. **告警/任务**：监测指标 → 触发告警 → 生成任务 → 分配负责人 → 记录处理结果。

## 6. 数据 & API
- 表：`warehouses`、`warehouse_zones`、`warehouse_locations`、`warehouse_capabilities`、`warehouse_channels`、`warehouse_metrics`、`warehouse_tasks`、`warehouse_audit_logs`。
- API：`GET/POST /api/warehouses`、`PATCH /api/warehouses/{id}`、`POST /api/warehouses/{id}/zones`、`GET /api/warehouses/{id}/metrics`、`POST /api/warehouses/{id}/tasks`。

## 7. 权限 & 审计
- 权限：`warehouse.read`、`warehouse.manage`、`warehouse.zone`、`warehouse.metrics`、`warehouse.tasks`。
- 审计：仓库配置、库区变更、任务操作记录；敏感字段需权限控制。

## 8. KPI
| 指标 | 目标 |
| --- | --- |
| 仓库上线周期 | ≤ 10 天 |
| 配置准确率 | ≥ 99% |
| 告警响应时间 | < 1 小时 |
| 数据同步延迟 | < 5 分钟 |

## 9. 风险
- 数据不准确导致调拨/履约错误；需严谨的审批与日志。
- 外部 WMS 对接复杂；需标准 API 与测试。
- 权限控制不当引发安全风险。
