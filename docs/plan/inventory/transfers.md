# 调拨 & 波次 PRD

> 覆盖页面：`web-admin/app/pages/inventory/transfers.vue` 以及计划新增的调拨详情、波次派工 UI。该模块负责仓库之间、仓库与门店之间的调拨，支持审批、物流、波次任务、异常处理。

## 1. 背景与目标
- 当前页面仅列出调拨单，需要支持调拨流程（申请→审批→拣货→运输→入库）、波次优化、物流跟踪、异常处理、任务协同。

**目标**
1. 管理调拨需求：来源（补货、渠道、活动、退货）、数量、优先级、渠道/仓库、时间窗口。
2. 提供审批、波次计划、作业指令、物流跟踪、入库确认。
3. 处理调拨异常（缺货、运输延迟、损耗），记录日志与审计。

## 2. 信息架构
1. **调拨看板**
   - 指标：调拨在途、完成率、异常、平均时效、波次负载。
   - 筛选：来源仓、目标仓、渠道、状态、优先级、SKU。
2. **调拨单列表**
   - 字段：调拨单号、来源/目的仓（或门店）、渠道、SKU/数量、状态（草稿/审批/拣货/运输/入库）、物流公司、运输方式、优先级、创建时间、负责人。
   - 操作：查看、编辑、审批、生成波次、打印单据、跟踪物流。
3. **调拨详情**
   - 基本信息、SKU 列表、箱单、批次、保质期、备注。
   - 流程节点：申请→审批→拣货→运输→入库→结算；每一步的时间、操作人、任务。
   - 物流信息：承运商、运单号、轨迹、异常。
   - 波次：若多单合并波次，展示波次计划、执行情况。
   - 异常：缺货、破损、延迟、差异处理。
4. **波次管理**
   - 波次计划列表：波次号、仓库、时间窗口、任务数、状态、作业人员。
   - 波次详情：包含的调拨单/订单、拣货路径、优先级、完成率。

## 3. 功能清单
| 功能 | 描述 |
| --- | --- |
| 调拨申请 | 基于补货建议、渠道请求、手动创建；可批量导入 |
| 审批流程 | 支持多级审批（仓库主管、供应链、财务），阈值配置 |
| 波次计划 | 自动/手动规划波次，分配任务、路径、人员 |
| 拣货/包装 | 生成拣货单、标签、包装任务，与仓库作业系统对接 |
| 物流跟踪 | 选择承运商、生成运单、实时更新轨迹、异常提醒 |
| 入库确认 | 目标仓/门店确认收货，更新库存、记录差异 |
| 异常处理 | 缺货、破损、延迟、退回，生成任务、备注、补单 |
| 报表 | 调拨成本、时效、成功率、波次效率 |

## 4. 流程
1. **申请**：系统/人工创建调拨 → 审批。
2. **拣货波次**：审批通过 → 自动分配至波次 → 拣货/包装 → 发货。
3. **运输**：承运商接单 → 运单更新 → 异常处理（延迟、破损）。
4. **入库**：目标仓确认 → 库存更新 → 结算/成本记录。

## 5. 数据 & API
- 表：`transfer_orders`、`transfer_items`、`transfer_tasks`、`transfer_wave_plans`、`transfer_logs`、`transfer_alerts`。
- API：`GET/POST /api/transfers`、`PATCH /api/transfers/{id}`、`POST /api/transfers/{id}/approve`、`POST /api/transfers/{id}/ship`、`POST /api/transfers/{id}/receive`、`GET /api/transfers/{id}/tracking`。

## 6. 权限 & 审计
- 权限：`transfer.read`、`transfer.manage`、`transfer.approve`、`transfer.wave`、`transfer.tracking`。
- 审计：调拨申请、审批、仓库作业、物流、入库、异常处理均记录；需保留附件/照片。

## 7. KPI
| 指标 | 目标 |
| --- | --- |
| 调拨完成时效 | ≤ 3 天（视距离） |
| 异常率 | < 2% |
| 波次按时完成率 | ≥ 95% |
| 数据同步 | < 10 分钟 |

## 8. 风险
- 波次规划不合理导致延迟；需算法与人工干预。
- 物流异常无法及时处理；需告警与任务。
- 多仓操作复杂，需权限、日志、培训。

## 9. Backlog
- 智能波次规划、路线优化。
- 与 TMS/第三方物流对接。
- 物联网设备上传输状态（温度、震动）。
- 结算成本自动分配。
