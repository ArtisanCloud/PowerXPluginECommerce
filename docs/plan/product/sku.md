# SKU & 变体管理 PRD

> 覆盖路径：`web-admin/app/pages/product/skus/index.vue`、`product/inventory.vue`、`product/spus/edit/**` 中的 SKU 区块，以及计划中的 SKU 生成器、批量调整、库存同步工具。

## 1. 背景与目标
- SKU（库存量单位）承载具体可售变体信息：规格组合、条码、重量、价格、库存等，是连接库存、渠道、定价的核心。
- 现有页面提供基本列表示例，需要完善 SKU 生成、批量编辑、与库存/渠道的联动。

**目标**
1. 提供从 SPU 属性自动生成 SKU 的能力，支持批量编辑与差异化配置。
2. 与定价、库存、渠道上架紧密联动，保障数据一致。
3. 支持批量导入/导出、条码打印、库存预警、序列号管理等扩展功能。

## 2. 用户与角色
| 角色 | 诉求 |
| --- | --- |
| 商品运营 | 快速生成/维护 SKU，配置规格、媒体、渠道差异 |
| 库存/仓库 | 查看 SKU 库存、批次、条码，执行补货/调拨 |
| 渠道运营 | 维护渠道映射、SKU 状态，推送上架 |
| 定价经理 | 关联价目表、合同价，批量调整价格 |
| 数据/开发 | 通过 API 同步 SKU 数据到外部系统 |

## 3. 信息架构
1. **SKU 列表 (`skus/index.vue`)**
   - 列字段：SKU 编码、SPU、规格组合、条码、库存、状态、价格、渠道、更新时间。
   - 筛选：SPU、类目、规格值、状态、渠道、库存区间、标签。
   - 批量操作：上/下架、价格/库存调整、导出、打印条码、指派仓库。
2. **SKU 生成器**
   - 来源：从 SPU 的规格/属性生成笛卡尔积，支持手动勾选生成。
   - 支持设置默认值：条码、成本、起订量、单位、重量、尺寸。
   - 提供“复制 SKU”“同步属性”功能。
3. **SKU 详情**
   - 基础：规格、编码、条码、生命周期、状态、可售渠道。
   - 价格：关联价目表、阶梯价、客户专属价指针。
   - 库存：实时库存、锁定、在途、补货计划。
   - 媒体：针对 SKU 的图片/视频（如不同颜色）。
   - 物流：重量、尺寸、包装、HS Code。
   - 合作方：供应商、采购价、交期、MOQ。
4. **变体管理**
   - 可视化矩阵：按两个规格展示，支持快速编辑（如颜色/尺码矩阵）。
   - 变体分组：同类 SKU 可分组管理（例如捆绑售卖）。

## 4. 功能清单
| 功能 | 描述 |
| --- | --- |
| SKU 生成 | 从 SPU 规格组合生成 SKU，支持过滤、批量创建 |
| 批量编辑 | 在列表/矩阵中批量更新价格、库存、条码、渠道状态 |
| 渠道映射 | 配置每个渠道的 SKU ID、状态、上架时间 |
| 条码/编码管理 | 支持自动生成、导入、校验唯一性，打印条码 |
| 库存联动 | 与 `inventory/**` 数据同步，展示实时库存与预警 |
| 价格联动 | 与 `pricing/**` 关联价目表、阶梯价、促销价 |
| 多媒体 | SKU 级别的图片/视频，设置主图、渠道专属图 |
| 导入导出 | Excel/CSV 模板，支持局部字段导入 |
| 批量上架/下架 | 设置生效时间、渠道，触发 `channels/sku-mapping` |
| 序列号/批次 | 可选模块，记录 SN、有效期、批次号 |

## 5. 关键流程
1. **SKU 生成**
   1. 在 SPU 编辑页选择规格 → 打开 SKU 生成器。
   2. 系统计算所有组合，允许勾选/取消，设置默认值。
   3. 点击生成后写入 SKU 列表，可继续编辑细节。
2. **批量价格/库存调整**
   1. 在 SKU 列表勾选若干条 → 选择“批量调整价格/库存”。
   2. 弹窗输入调整方式（固定值/百分比/导入模板），提交后生成任务。
   3. 任务完成后更新 SKU，并记录审计。
3. **渠道映射**
   1. SKU 详情选择渠道 → 输入渠道 SKU ID、状态、库存同步方式。
   2. 发布至渠道，记录映射关系；若渠道返回错误，显示在任务日志。
4. **条码管理**
   1. 支持自动生成 EAN/UPC；或导入已有条码。
   2. 校验重复，支持批量打印条码标签。

## 6. 数据 & API
- **表**：`product_skus`、`product_sku_attributes`、`product_sku_channels`、`product_sku_media`、`product_sku_tags`、`product_sku_inventory`、`product_sku_audit_logs`。
- **API（示例）**：
  - `GET /api/products/skus`、`POST /api/products/skus`、`PATCH /api/products/skus/{id}`、`DELETE /api/products/skus/{id}`。
  - `POST /api/products/spus/{id}/skus/generate`（生成器）。
  - `POST /api/products/skus/import`、`POST /api/products/skus/export`。
  - `POST /api/products/skus/bulk-update`（价格/库存/状态）。
  - `POST /api/products/skus/{id}/channels`（映射）、`POST /api/products/skus/{id}/channels/publish`。
  - `GET /api/products/skus/{id}/inventory`（实时库存）。

## 7. 权限与审计
- 权限：`product.sku.read`、`product.sku.manage`、`product.sku.bulk`、`product.sku.channel`。
- 审计：记录生成、编辑、批量操作、渠道推送、库存调整等；关联 `admin_console_audit_events`，并可在 SKU 详情展示最近操作。

## 8. KPI / 衡量
| 指标 | 目标 |
| --- | --- |
| SKU 生成效率 | 50 个 SKU 的生成/配置过程 ≤ 10 分钟 |
| 批量任务成功率 | ≥ 98% |
| 渠道映射准确率 | ≥ 99% |
| 库存同步时延 | ≤ 5 分钟 与 inventory 数据保持一致 |

## 9. 依赖与风险
- 强依赖属性/规格模块；需要确保规格组合合法、可控。
- 与库存、定价、渠道高度耦合，任何变更都需幂等处理。
- 批量操作易出错，需要完善的校验、预览、回滚机制。
- 条码与序列号涉及唯一性和合规，需校验国际标准。

## 10. Backlog
- SKU 预配置模板：按渠道/地区生成不同属性集。
- AI 辅助：推荐热销规格组合、库存预警建议。
- 虚拟 SKU：支持服务、数字商品等非实体 SKU。
- BOM/组装：支持组合 SKU、BOM 结构，与生产/库存联动。
- API Webhook：SKU 变更通知第三方系统。
