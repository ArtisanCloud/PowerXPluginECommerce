# 供应商管理 PRD

> 覆盖页面：`web-admin/app/pages/product/suppliers.vue` 及后续扩展的供应商档案、合同、评价、协同组件。此模块作为电商插件在商品域中的“供应侧入口”，与采购、库存、定价、结算模块联动，承载供应商账号、资质、供货能力等数据。

## 1. 背景与目标
- 电商插件不仅要管理商品，还需掌握供应链端的合作方，形成“供应商 → 商品 → 渠道”闭环。
- 现有页面展示供应商列表及概览指标，需要明确如何通过该模块为商品、采购、库存带来价值。

**目标**
1. 搭建供应商主数据：基础信息、联系人、账号、资质、合同、税务信息。
2. 记录供货能力：可供 SPU/SKU、MOQ、交期、价格、质量评分，为采购决策和渠道上架提供依据。
3. 与采购、库存、结算、质检模块打通，实现任务协同、绩效评价、风险预警。

## 2. 角色与价值
| 角色 | 价值 |
| --- | --- |
| 商品/采购运营 | 快速查询可用供应商，了解资质、供货 SKU、报价，发起采购或补货流程 |
| 供应链经理 | 维护合同、KPI、风险，分配供应商等级，指导采购策略 |
| 仓储/质检 | 查看供应商履约记录，追踪质检问题，触发处罚或整改 |
| 财务/结算 | 获取供应商银行、税务、结算周期，核对发票与分账 |
| 供应商（可选 Portal） | 通过账号登录提交资料、更新供货信息、查看订单与结算 |

## 3. 信息架构
1. **供应商概览（Dashboard）**
   - KPI：总数、活跃率、评分、合作金额、风险预警。
   - 预警模块：即将过期合同、低评分、交货延迟、质检不合格。
2. **供应商列表**
   - 列字段：供应商名称、类型（制造/贸易/代工）、所属分类、联系人、状态、评分、合作金额、关联 SKU 数量。
   - 筛选：状态、类别、地区、评分、供货品类、风险等级、是否核心供应商。
   - 支持批量操作（导出、分配负责人、标签、评级）。
3. **供应商档案详情**
   - 基础信息：注册资料、联系人、账号、地址、证照、税务、银行、发票类型。
   - 合同 & 资格：合同列表、有效期、附件、审批记录。
   - 供货能力：覆盖类目、SPU/SKU 列表、MOQ、交期、价格、产能、渠道限制。
   - 绩效评价：质量、交期、成本、协作评分，图表化展示。
   - 风险 & 处罚：黑名单、整改记录、异常订单。
   - 协同：备注、任务、沟通记录、附件。
4. **供应商账号管理**
   - 若启用供应商门户，可在此创建/绑定供应商账号、角色与权限（与 PowerX 底座权限体系对接）。

## 4. 功能清单
| 功能 | 描述 |
| --- | --- |
| 新建/导入供应商 | 支持手动创建 & CSV 导入；校验重复、资质、KYC |
| 审核流程 | 供应商资料、合同需经过审批（采购经理/法务/财务）；状态切换由审批驱动 |
| 标签 & 分级 | 自定义标签（核心/战略/临时）、评分等级、黑名单管理 |
| SKU 绑定 | 维护供应商可供的 SPU/SKU，包括价格、MOQ、交期、渠道限制；支持导入导出 |
| 合同 & 附件 | 上传合同、协议、质检标准，记录版本、提醒到期 |
| 绩效考核 | 统计订单履约率、质检通过率、投诉率，生成评分与趋势 |
| 风险预警 | 根据 KPI 触发告警（延迟、缺货、评分下降），可升级至风险管理模块 |
| 协作 & 通知 | 在详情页记录沟通、任务、附件；与消息中心、审批流集成 |
| 供应商账号 | 创建供应商 Portal 账号，配置权限、重置密码、停用 |

## 5. 关键流程
1. **供应商入驻**
   1. 采购提交“新建供应商”或供应商通过 Portal 填写表单。
   2. 系统校验（重复、黑名单、证照有效期）。
   3. 进入审批流（采购经理 → 品控 → 法务 → 财务）。
   4. 审批通过后状态变为“活跃”，可绑定 SKU、参与采购。
2. **SKU 绑定/维护**
   1. 在供应商详情中选择“绑定商品” → 按类目/搜索选择 SPU/SKU。
   2. 填写 MOQ、交期、供货价、渠道限制。
   3. 支持从 Excel 导入批量绑定，或从 SKU 详情反向选择供应商。
3. **绩效更新**
   1. 从订单/库存系统获取交付、质检、退货等数据。
   2. 周期性计算评分、生成排名、输出改进建议。
   3. 对低评分供应商自动发起整改任务或暂停状态。
4. **账号与协同**
   1. 供应链经理为已审核供应商创建账号，分配 Portal 角色。
   2. 供应商可登录查看订单、提交发货信息、更新资料；操作记录写回该模块。

## 6. 数据 & API
- **表**：`suppliers`、`supplier_contacts`、`supplier_documents`、`supplier_contracts`、`supplier_products`、`supplier_prices`、`supplier_metrics`、`supplier_accounts`、`supplier_logs`。
- **API（示例）**：
  - `GET /api/suppliers`、`POST /api/suppliers`、`PATCH /api/suppliers/{id}`、`POST /api/suppliers/{id}/status`。
  - `POST /api/suppliers/import`、`POST /api/suppliers/export`。
  - `POST /api/suppliers/{id}/products`（绑定 SKU）、`DELETE /api/suppliers/{id}/products/{skuId}`。
  - `GET /api/suppliers/{id}/metrics`、`POST /api/suppliers/{id}/contracts`、`POST /api/suppliers/{id}/accounts`。
  - `GET /api/suppliers/{id}/logs`（审计/沟通记录）。

## 7. 权限与审计
- 权限项：`supplier.read`、`supplier.manage`、`supplier.contract`、`supplier.metrics`、`supplier.account`、`supplier.approval`。
- 所有关键操作（新建、修改、SKU 绑定、合同上传、账号变更）写入 `admin_console_audit_events`，记录操作者、字段变更、审批链。
- 对供应商 Portal 账号的创建/禁用需二次验证，防止误操作。

## 8. KPI / 衡量
| 指标 | 目标 |
| --- | --- |
| 供应商审核周期 | 新供应商 ≤ 5 个工作日 |
| 90 天内活跃率 | ≥ 85% |
| 履约准时率 | ≥ 95% |
| 质检合格率 | ≥ 98% |
| 供应商评分提升 | 平均评分每季度提升 ≥ 0.1 |

## 9. 依赖与风险
- 依赖采购、库存、质检、结算模块提供订单/交付/质检/付款数据，确保 KPI 真实。
- 供应商信息涉及合规与资质管理，需要与 PowerX 底座的文档/审批组件对接，避免重复实现。
- 若启用供应商 Portal，需整合 PowerX 统一身份认证与权限体系。
- 数据敏感性高（合同、付款信息），需严格控制访问与审计。

## 10. Backlog
- 供应商 Portal：开放自助更新资料、查看订单/结算、提交发货/质检信息。
- 评分算法：引入 AI/ML 计算评分与风险预测。
- 供需匹配：根据库存/订单预测，推荐供应商补货计划。
- 区域供应商地图：可视化供应商分布，支持灾备与多区域策略。
- 协议价联动：与定价中心、合同价模块双向同步协议价格。
