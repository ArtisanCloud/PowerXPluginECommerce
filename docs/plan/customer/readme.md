# 客户模块场景与功能规划

> 适用范围：`web-admin/app/pages/customer/index.vue`、`customer/members.vue` 及其依赖的客户详情模态、批量操作组件、API 层。

## 1. 背景与目标
- **业务背景**：电商插件需要为客服、运营、营销等多角色提供统一客户视图，覆盖“获客→激活→复购→售后”的全链路。现阶段页面以 Mock 数据驱动，缺乏真实 CRM/订单/营销数据打通。
- **目标**：
  1. 构建客户 360 画像（基础信息、订单、权益、互动、风控）。
  2. 支撑运营动作（批量导入导出、标签管理、任务分派、批量发券）。
  3. 提供会员视角（等级、权益、成长值）与客户细分（标签/分群/渠道）。
  4. 实现端到端审计，确保每次改动、导出都有记录。

## 2. 用户与场景
| 角色 | 核心任务 | 关键诉求 |
| --- | --- | --- |
| 客服/售后 | 查客户信息、订单、售后状态 | 快速检索、统一历史、可发起售后/补货请求 |
| 运营（CRM） | 维护客户标签、会员权益、推送活动 | 批量操作安全、分群精准、与营销联动 |
| 数据分析/营销 | 查看客户生命周期、渠道转化 | 细分维度可配置、可导出、指标可订阅 |
| 合规/风控 | 审核导入导出、查看操作日志 | 审计闭环、权限可控、异常告警 |

## 3. 功能结构
1. **客户列表**（`customer/index.vue`）
   - 筛选：渠道、会员等级、标签、活跃度、国家、最近订单时间。
   - 视图：表格/卡片切换，支持保存筛选器。
   - 列表操作：批量选择后可执行导出、标签打标、发券、分配负责人。
   - 导入/导出：页头按钮唤出 `CustomerImportDialog`、`CustomerExportDialog`。导入限制 `customer.manage` 权限，导出需 `customer.export`。
2. **客户详情抽屉/页**
   - 概览：基本资料、会员状态、成长值、最近登录。
   - 订单与售后：最近 5 单 + 快捷跳转更多、售后状态提示。
   - 互动时间线：工单、营销发送/触达、积分变动、系统事件。
   - 权益 & 限制：可享优惠、包邮资格、风控黑名单标记。
   - 快捷操作：重置密码、禁用账号、发优惠券、创建任务。
3. **会员视角**（`customer/members.vue`）
   - 以会员等级、成长值段位、权益包使用情况为主轴显示客户。
   - 指标卡（`MembershipCards`）实时展示总数/活跃/即将降级/平均成长值。
   - `MembershipReminderDrawer` 支持短信/邮件/站内保级提醒，调用 `POST /customers/bulk-remind`，带 KPI 事件（SC-003、SC-004）。
   - 同步复用导入/导出对话框，导出默认字段为会员视角关键数据。
4. **批量导入/导出**
   - 导入：模板下载、字段映射、校验、预览、审批（>1k 条需审批）。前端将文件上传至 `/customers/import` 并记录任务中心 ID。
   - 导出：根据筛选条件导出 CSV/Excel，写入审计日志并支持异步下载。任务完成后提供签名链接；页面记录 KPI（导出耗时）。
5. **标签 & 分群管理**
   - 右侧标签面板：新建、合并、颜色标记。
   - 支持 Pinia store 同步标签树，便于其他模块复用。
6. **权限控制与审计**
   - 与 `/settings/roles.vue` 对接；支持按角色限制批量操作、导出。
   - 所有写操作调用后端 `admin_console_audit_events` 记录审计，前端通过 `AuditContext` 自动注入 `X-Audit-Action/Resource`。

### 3.1 指标与可观测性
- 统一通过 `useCustomerMetrics` 上报：
  - `customer_list_fetch` / `customer_membership_fetch`：筛选响应耗时（SC-001）。
  - `customer_export_task` / `customer_import_task`：导入导出任务创建、完成时长（SC-002）。
  - `customer_reminder_task` + `recordReminderResult`：保级提醒成功/失败率（SC-003/SC-004）。
  - 自定义事件：`customer_import_modal_open`、`customer_export_modal_open` 用于统计入口使用频次。
- 指标推送至宿主任务中心/监控，Quickstart 中提供验证步骤：筛选 ≤ 3 次点击即可命中目标、导出任务 ≤ 10 分钟完成。

## 4. 流程示意
1. **客户导入**
   1. 运营选择“批量导入” → 上传模板 → 映射字段 → 预览。
   2. 系统执行字段/重复校验 → 生成任务 → 若超阈值则进入审批。
   3. 审批通过后写入客户表，并记录导入批次 + 审计 ID。
2. **客户详情操作**
   1. 客服在列表点击客户 → 抽屉加载基本信息与时间线。
   2. 可直接点击“发券”打开模态（复用积分/优惠券 API）。
   3. 完成操作后更新时间线、触发通知/审计记录。
3. **会员保级提醒**
   1. 定时任务计算客户成长值与即将降级名单。
   2. 在 `members.vue` 展示“即将降级”块，允许批量发送提醒/优惠券。

## 5. 数据与接口需求
- **核心表**：`customers`、`customer_profiles`、`customer_tags`、`customer_membership`、`customer_activity_logs`。
- **后端接口**（示例）：
  - `GET /api/customers`：分页查询，支持多条件过滤。
  - `GET /api/customers/:id`：详情 + 关联（订单、售后、积分）。
  - `POST /api/customers/import`：创建导入任务。
  - `POST /api/customers/export`：导出任务，返回任务 ID。
  - `POST /api/customers/:id/actions`：发券、禁用、标签调整等统一入口。
- **实时性**：关键指标（最近订单金额/时间）需通过事件或定时任务刷新，不要求强实时但需保证 15 min 内一致。

## 6. 权限与审计
- 读权限：`customer.read`；写权限：`customer.manage`；导出权限：`customer.export`。
- 批量操作、导入、导出均写入 `admin_console_audit_events`，并附上筛选条件、操作者、耗时。
- 对敏感字段（手机号、邮箱）需 Mask，只有具备 `customer.sensitive.read` 权限才展示完整信息。

## 7. KPI 与验收标准
| 指标 | 目标 |
| --- | --- |
| 页面加载时间 | 列表首屏 < 2s（含 20 条记录） |
| 数据准确率 | 导入校验覆盖率 100%，导入失败提示明确 |
| 审计覆盖率 | 100% 写操作带有审计 ID |
| 运营效率 | 批量操作可处理 ≥ 1k 客户且 5 分钟内完成 |

## 8. 依赖与风险
- 依赖订单、售后、营销、积分等服务提供聚合 API；需在 `backend/internal/services/customer` 旁构建聚合层。
- 批量导入/导出需考虑异步任务队列（如 Redis / RQ）。
- 风控：防止恶意导出/操作，可增加操作节流与审批机制。

## 9. 迭代计划
1. **MVP（当前迭代）**：接入实时 CRM API，完善列表筛选、详情抽屉、基本批量操作。
2. **迭代 2**：上线批量导入/导出 + 审批；接入会员成长、权益展示；与营销模块联动发券。
3. **迭代 3**：补齐 360 时间线、风控提示、任务派发；开放 Webhook/事件订阅。
