# 积分与成长值 PRD

> 覆盖路径：`/customer/membership/points/**`、`/customer/membership/growth-value/**`，以及批量调账模态（`BatchAdjustPointsModal.vue`、`BatchAdjustGrowthValueModal.vue`）。

## 1. 背景与目标
- 积分/成长值体系联动会员等级、权益兑换、营销激励，是客户复购与忠诚度的核心抓手。
- 目前前端提供规则、账户、商城等示例，需要明确业务要求与互通接口。

**目标**
1. 建立统一的积分与成长值规则引擎，支持多触点发放/消耗。
2. 管理账户余额、流水、锁定机制，提供批量调整与风控审批。
3. 打通权益兑换（礼品、优惠券）、任务成长、保级提醒等场景。
4. 保障审计、权限、风控全链路可追溯。

## 2. 用户与角色
| 角色 | 诉求 |
| --- | --- |
| 会员运营 | 配置积分/成长规则、策划活动、监控余额和过期情况 |
| 客服/售后 | 查询账户、手动调账、处理争议 |
| 财务/审计 | 追踪成本、核对批量操作和批次审批 |
| 技术运维 | 监控任务执行、定时器、异常预警 |

## 3. 信息架构
1. **积分规则中心 (`points/index.vue`)**
   - 发放规则：消费、签到、任务、推荐、活动奖励。
   - 消耗规则：兑换优惠券、礼品、抵扣现金、调账。
   - 规则属性：触发条件、渠道、生效时间、上限、审批要求。
2. **积分账户 (`points/accounts/**`)**
   - 账户列表：客户、当前积分、锁定积分、即将过期。
   - 账户详情：流水、来源、过期计划、锁定记录。
   - 支持批量锁定/解锁、导入/导出。
3. **积分商城 (`points/mall.vue`)**
   - 兑换礼品、优惠券、权益；支持搜索、分页、库存提醒。
   - 兑换流程：选择商品 → 校验条件 → 扣积分 → 触发履约（发券/发货）。
4. **成长值中心 (`growth-value/index.vue`)**
   - 成长值规则：晋升、降级、任务奖励，关联会员等级保级。
   - 账户：与积分类似，支持查看成长值历史。
   - 应用：保级提醒、成长任务、推荐任务、自动调整等级。
5. **批量操作 & 审批**
   - Batch 模态：批量调整积分/成长值，支持上传名单、设定原因、审批链。
   - 操作记录：与审计日志、风控联动。

## 4. 功能详解
| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 积分规则 | CRUD、启停、版本管理 | DSL 配置，支持 JSON 导入导出 |
| 任务配置 | 定义任务类型、奖励 | 与营销任务/增长实验共用组件 |
| 流水查询 | 多条件筛选、导出 | 过滤条件：客户、渠道、规则、日期、状态 |
| 锁定机制 | 下单锁定、取消释放 | 配置锁定时长、超时处理 |
| 过期管理 | 定时计算、通知策略 | 自定义过期策略，批量提醒 |
| 积分商城 | 商品管理、库存、兑换流程 | 商品可关联 SPU/SKU 或优惠券模板 |
| 成长值规则 | 晋升/降级、任务加成 | 支持多权重（消费、任务、活动） |
| 批量调账 | 导入名单、审批、执行 | 分为“立即执行”“定时执行”，支持撤回 |

## 5. 关键流程
1. **积分发放**
   1. 消费/任务事件触发 → 调用规则引擎计算积分。
   2. 引擎校验上限、黑名单 → 生成流水、写入账户。
   3. 若需审批，进入待审批队列，审批通过后生效；否则立即生效。
   4. 系统记录审计：触发源、规则、积分值、操作者/系统。
2. **积分兑换**
   1. 会员在后台客服或自助入口发起兑换 → 检查积分余额、库存、限购。
   2. 扣减积分并生成兑换记录。
   3. 若兑换的是优惠券：调用营销券 API 发券；若是礼品：创建发货任务。
   4. 通知会员（邮件/短信/站内），并写流水 + 审计。
3. **成长值保级**
   1. 定时任务计算各会员的成长值与等级阈值。
   2. 对即将掉级的会员放入“保级任务”，推送提醒或自动加速。
   3. 完成任务或补足成长值后自动更新等级，并写入会员模块。
4. **批量调整**
   1. 运营上传名单 + 调整方案 → 系统校验（格式、上限、风险）。
   2. 若金额超阈值需审批，多级签核后执行。
   3. 执行任务写流水 + 审计，通知相关负责人。

## 6. 数据 & 接口
- **表结构**：`loyalty_points_accounts`、`loyalty_points_transactions`、`loyalty_rules`、`loyalty_tasks`、`growth_value_accounts`、`growth_value_transactions`、`loyalty_batch_jobs`。
- **API（示例）**：
  - `GET /api/loyalty/points/accounts`、`GET /api/loyalty/points/accounts/:id`。
  - `POST /api/loyalty/points/rules`、`PATCH /api/loyalty/points/rules/:id`、`POST /api/loyalty/points/rules/:id/toggle`。
  - `POST /api/loyalty/points/batch-adjust`、`POST /api/loyalty/growth/batch-adjust`。
  - `POST /api/loyalty/points/mall/orders`（兑换）、`GET /api/loyalty/points/mall/items`。
  - `POST /api/loyalty/growth/tasks`、`POST /api/loyalty/growth/simulate`。

## 7. 权限与风控
- 权限项：`loyalty.points.read`、`loyalty.points.manage`、`loyalty.points.batch`、`loyalty.growth.read/manage`、`loyalty.mall.manage`。
- 风控策略：
  - 高额批量调账需审批 + 二次验证码。
  - 兑换异常（短时间大量兑换）触发风控队列。
  - 积分赠送上限、黑名单（禁止参与活动）。
- 审计：流水、批量任务、规则变更全部写入 `admin_console_audit_events`，并记录操作人、IP、上下文。

## 8. KPI / 衡量
| 指标 | 目标 |
| --- | --- |
| 积分发放准确率 | ≥ 99.9% |
| 积分过期提醒覆盖率 | ≥ 95% 即将过期会员收到提醒 |
| 批量任务 SLA | 30 分钟内执行完成 |
| 风控命中率 | 发现 ≥ 90% 的异常兑换行为 |

## 9. 依赖与风险
- 依赖订单、支付、营销券、库存等系统提供事件和 API。
- 积分/成长值规则计算需兼顾性能，可能需要异步引擎或缓存。
- 兑换履约涉及发货/发券，需保证幂等与补偿机制。
- 安全：防止脚本刷积分/兑换，需限制频率、加入人机验证。

## 10. Backlog
- **积分/成长值 API** 对接前台自助门户与移动端。
- **AI 推荐**：根据客户行为推荐兑换商品或任务。
- **积分投资**：允许积分抵扣现金或参与理财/预售。
- **多币种**：支持不同区域使用多种积分单位，统一结算。
