# 代币 / 数字权益 PRD

> 面向未来要引入的代币（Token）体系，可被视作积分/礼品卡之外的第三种权益资产，用于周期订阅、增值服务、生态互转。它与 `docs/plan/customer/points-growth.md`（积分/成长值）和 `docs/plan/pricing/giftcards.md`（礼品卡）联动，但具有更灵活的发行/兑换/支付能力。

## 1. 背景与目标
- 部分业务需要“面额自由、可转存储、可跨产品使用”的数字资产，例如订阅抵扣、增值服务、跨生态兑换。需要一个代币中心统一发行、管理、流通。

**目标**
1. 管理代币的发行、销毁、余额、账本、权限，支持多种用途（订阅抵扣、活动奖励、跨项目结算）。
2. 与支付/结算/财税协同，确保代币在资金流、税务、风控上可追踪。
3. 提供 API/Portal，让客户或合作伙伴可查询、转移、授权代币。

## 2. 信息架构
- 代币定义：Token Code、名称、描述、类型（可充值/不可充值、稳定值/浮动值）、精度、基础价值（折算货币）。
- 发行批次：数量、成本、用途、渠道、有效期、可转让性、审批。
- 账户与余额：客户/租户代币账户、余额、锁定、可用额度、授权。
- 交易/账本：发放、扣减、转账、冻结、解冻、兑换、回收，记录来源与关联业务（订单、订阅、活动）。
- 用途配置：代币可用于抵扣订阅周期、兑换商品/权益、支付手续费、结算佣金；可设置使用优先级、叠加规则。
- 风控：黑名单、限额、频率、异常监控。

## 3. 功能清单
| 功能 | 描述 |
| --- | --- |
| 代币定义 | 创建/编辑代币，配置精度、价值、用途、可转让性、权限 |
| 发行批次 | 按批次发行、审批、绑定活动/渠道、成本核算 |
| 账户管理 | 为客户/租户/合作伙伴创建账户，查看余额、授权、冻结 |
| 交易账本 | 记录所有交易，支持筛选、导出、审计，与支付/结算对账 |
| 抵扣规则 | 设置代币用于订阅、订单、手续费的抵扣比例、优先级 |
| 转移 | 在客户之间转移（可选），支持审批、KYC |
| API & Portal | 提供查询/发放/扣减 API、客户 Portal、自助查看与授权 |
| 风控 & 审计 | 限额、风控策略、审计日志、告警 |

## 4. 流程示例
1. **发行**：创建代币 → 配置用途、精度 → 创建发行批次 → 审批 → 发放至活动/客户。
2. **使用**：用户在订阅/订单结算时选择使用代币，系统根据规则扣减，并更新账本。
3. **转移/授权**：用户授予订阅自动扣费授权，代币系统定期扣减；可设置上限与撤销。
4. **回收/注销**：代币过期或活动结束，自动回收或冲销；记录财务影响。

## 5. 数据 & API
- 表：`token_definitions`、`token_batches`、`token_accounts`、`token_transactions`、`token_authorizations`、`token_rules`、`token_audit_logs`。
- API：`POST /api/tokens`、`POST /api/tokens/{id}/issue`、`POST /api/tokens/accounts/{accountId}/credit`、`POST /api/tokens/accounts/{accountId}/debit`、`POST /api/tokens/accounts/{accountId}/transfer`、`GET /api/tokens/accounts/{accountId}`。

## 6. 权限 & 审计
- 权限：`token.read`、`token.manage`、`token.issue`、`token.transfer`、`token.audit`。
- 审计：所有发行、调整、扣减、授权操作需记录，附带业务上下文；与 `admin_console_audit_events` 对齐。

## 7. KPI
| 指标 | 目标 |
| --- | --- |
| 发行审批周期 | ≤ 2 天 |
| 账本准确率 | ≥ 99.9% |
| 异常拦截率 | ≥ 98% |
| 代币使用率 | ≥ 70%（视场景） |

## 8. 风险
- 代币涉及财务/税务，需要合规处理，尤其是可兑换货币价值时；与财税模块对齐。
- 安全风险：需要权限、加密、限额、风控策略。
- 流动性/价值波动：如设定自有价值，需要政策与财务支持。

## 9. Backlog
- 与区块链/分布式账本对接（可选）。
- 代币市场或二级交易功能（需合规评估）。
- 与订阅模块深度联动，自动续费扣代币。
- AI 风控模型识别异常使用。
