# 渠道主数据与授权 PRD

> 覆盖页面：`web-admin/app/pages/channels/index.vue`、`market/channels.vue` 以及后续需要的渠道详情、授权、团队配置界面。该模块负责渠道/店铺主数据、授权凭证、团队权限、KPI、健康度，是多渠道运营的入口。

## 1. 背景与目标
- 目前渠道页面仅展示卡片，需要完整的渠道主数据、授权流程、凭证刷新、权限、KPI 与告警，以支持多渠道扩展。

**目标**
1. 管理渠道/店铺基本信息：类型、平台、店铺 ID、域名、区域、负责人。
2. 记录授权凭证（API Key、Token、证书）、刷新周期、权限范围；提供自动检测与告警。
3. 展示渠道 KPI（GMV、订单、GMV 增长率、库存覆盖、错误率），提供健康度评分与告警。

## 2. 信息架构
1. **渠道列表**
   - 卡片或表格展示：名称、平台、状态（待授权、已授权、暂停）、负责人、GMV、订单、异常、最近同步。
   - 筛选：平台、状态、负责人、区域、GMV、健康度。
   - 操作：查看、授权、刷新凭证、暂停、删除、进入上架/映射。
2. **渠道详情**
   - 基础信息：店铺 ID、平台、域名、客服信息、联系人。
   - 授权信息：API 凭证、回调 URL、刷新 Token、权限范围、有效期、操作日志。
   - 配置：定价策略（引用 pricebook）、库存策略、物流策略、客服 SLA、手续费、账期、结算方式。
   - KPI & 健康度：KPI 卡、趋势、活跃度、错误率、告警。
   - 团队与权限：负责小组、可操作角色、审批流程。
   - 任务 & 备忘：关联的上架任务、异常、告警、备注。
3. **授权流程**
   - 表单：选择平台 → 跳转授权 → 回调 → 保存凭证 → 测试 API → 完成。
   - 支持手动录入（如线下渠道）、凭证文件上传。

## 3. 功能清单
| 功能 | 描述 |
| --- | --- |
| 渠道 CRUD | 新增/编辑/停用渠道，记录详细属性，走审批（新增渠道需审核） |
| 授权与凭证管理 | 平台授权流程、Token 刷新、自动检测、凭证加密、权限范围 |
| 配置管理 | 定价、库存、物流、客服策略、费率、账期、结算方式 |
| KPI & 健康度 | KPI 看板、健康度评分、告警，支持自定义指标 |
| 团队权限 | 分配负责人、审批人、操作权限；支持 Audit Trail |
| Notification | 授权即将过期、API 错误、健康度变差、库存不足告警 |
| 数据同步 | 记录同步时间、耗时、结果；支持手动刷新 |

## 4. 数据 & API
- 表：`channel_master`、`channel_credentials`、`channel_configs`、`channel_metrics`、`channel_alerts`、`channel_audit_logs`。
- API：`GET/POST /api/channels`、`PATCH /api/channels/{id}`、`POST /api/channels/{id}/authorize`、`POST /api/channels/{id}/refresh`、`GET /api/channels/{id}/metrics`。

## 5. 权限 & 审计
- 权限：`channel.master.read`、`channel.master.manage`、`channel.auth`、`channel.metrics`、`channel.alerts`。
- 审计：渠道新增、更改、授权、凭证、配置变更、告警处理，记录操作人和时间。

## 6. KPI
| 指标 | 目标 |
| --- | --- |
| 渠道上线周期 | ≤ 10 天 |
| 授权/凭证有效率 | ≥ 99% |
| 同步成功率 | ≥ 99% |
| 告警响应时间 | < 1 小时 |

## 7. 风险
- 凭证泄露/过期；需加密、访问控制、告警。
- 多渠道差异大，需要 Connector 框架支撑；需模块化设计。
- 数据同步失败；需重试、日志。
