# 渠道与上架模块规划总览

> 适用范围：`web-admin/app/pages/channels/**`、`web-admin/app/pages/market/channels.vue`、`market/marketing.vue` 中与渠道相关的组件，以及渠道授权、SKU 映射、上架发布、内容管理、渠道健康度监控等能力。渠道与上架模块连接商品、定价、库存、营销与各个销售平台，是电商插件的“多渠道适配层”。

## 1. 文档目的
- 梳理渠道/店铺主数据、授权流程、SKU 映射、内容适配、上架发布、渠道状态监控、健康度等子模块。
- 与商品、定价、库存、订单、营销、履约模块对齐接口，确保多渠道管理的复用性。

## 2. 当前页面覆盖
| 模块 | 前端路径 | 状态摘要 |
| --- | --- | --- |
| 渠道列表/授权 | `channels/index.vue`、`market/channels.vue` | 展示渠道卡片，缺少完整授权、凭证、KPI、健康度视图 |
| 上架发布 | `channels/publishing.vue` | 仅示例列表，需发布计划、日志、回滚 |
| SKU 映射 | `channels/sku-mapping.vue` | 基本表格，需属性/类目映射、自动匹配、异常处理 |
| 渠道配置 | 暂无独立页面 | 需要配置定价策略、库存同步、物流、客服策略 |
| 渠道监控 | 暂无 | 需 KPI、健康度、告警、任务 |

## 3. 角色与价值
| 角色 | 核心诉求 |
| --- | --- |
| 渠道运营 | 管理多渠道/店铺、授权、上架、促销、异常 |
| 商品/定价团队 | 了解渠道可售 SKU、内容要求、定价策略 |
| 库存/履约 | 确定每个渠道的库存策略、发货仓、配送方式 |
| 客服 | 知道渠道状态、异常、告警，及时响应 |
| 财务 | 管理渠道手续费、账期、分账策略 |

## 4. 功能规划概览
1. **渠道主数据与授权**：店铺信息、凭证、API 配置、权限、团队。
2. **SKU & 内容映射**：属性/类目映射、自动匹配、内容适配、差异化文案、审核。
3. **上架发布 & 版本管理**：商品选择、定价、库存、内容生成、发布计划、日志、回滚。
4. **渠道健康度**：KPI（GMV、订单、错误）、告警（授权失效、SKU 异常、库存不足）、任务协同。
5. **渠道配置**：定价策略引用、库存同步策略、物流/客服信息、运费模板。
6. **第三方接口**：预置 Shopify、Amazon、京东、天猫、拼多多等适配器，提供 `Connector` 框架。

## 5. 迭代路线
- Phase 1：渠道主数据、授权、SKU 映射、基本上架。
- Phase 2：内容适配、发布计划、渠道监控、告警。
- Phase 3：多渠道自动化发布、AB 测试、智能推荐。
- Phase 4：深度集成第三方平台（订单、履约、客服），自动化健康度预测。

## 6. 依赖
- 需与商品（SPU/SKU）、库存（可售库存、锁定）、定价（价目表、规则）、营销（促销/活动）、订单（渠道订单）、履约（运单）、支付（手续费）模块实现数据对齐。
