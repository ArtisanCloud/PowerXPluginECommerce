# 税率与税则 PRD

> 覆盖页面：`web-admin/app/pages/tax.vue`、订单/定价/结算中的税务配置。负责多地区税率、税类、税收规则、税务合规、发票设置。

## 1. 目标
- 管理多地区、多税种的税率（VAT、GST、Sales Tax）、税类（商品类型、服务）、税收规则（阈值、豁免），为定价、订单、结算、发票提供准确税务计算与校验。

## 2. 信息架构
- **税率列表**：国家/地区、税类、税率、有效期、供应商/渠道、状态、更新时间。
- **税则详情**：
  - 基础信息：税类、国家、省、市、税号、适用主体。
  - 规则：税率、计算方式（含税/不含税）、阈值、豁免条件、汇率、舍入。
  - 关联：商品分类、渠道、客户类型、发票类型。
  - 合规：证照/文档、备注、审批记录。

## 3. 功能
| 功能 | 描述 |
| --- | --- |
| 多地区税率 | 配置国家/地区、州、省、市税率；支持生效/失效时间 |
| 税类管理 | 商品/服务税类、组合、映射（HS Code、海关编码） |
| 规则引擎 | 条件（商品/客户/渠道/金额）→ 税率/豁免；支持图形和 DSL |
| 税率同步 | 与外部税务 API（AvaTax、TaxJar）同步；手动导入 |
| 税务校验 | 下单/发票前校验税务信息；支持提示/阻断 |
| 发票配置 | 配置发票类型、税号、发票模板、开票流程 |
| 审批/日志 | 税率变更需审批；记录日志、版本 |

## 4. 数据 & API
- 表：`tax_rates`、`tax_rules`、`tax_classes`、`tax_documents`、`tax_logs`。
- API：`GET/POST /api/taxes/rates`、`POST /api/taxes/rates/{id}/publish`、`GET /api/taxes/rules`、`POST /api/taxes/sync`（第三方）。

## 5. 权限 & 审计
- 权限：`tax.read`、`tax.manage`、`tax.approve`、`tax.sync`。
- 审计：税率变更、规则变更、发票配置调整；需记录版本和审批人。

## 6. KPI
| 指标 | 目标 |
| --- | --- |
| 税率更新时效 | < 24h |
| 税务合规率 | 100% |
| 计算准确率 | ≥ 99.9% |

## 7. 风险
- 多地区法规复杂，需法律/税务对接。
- 税率变动频繁；需自动化同步、通知。
- 错误税率导致罚款；需审批和回滚。

## 8. Backlog
- 自动生成税务申报数据。
- 税务机器人（FAQ、政策提醒）。
- AI 识别税务风险（异常订单）。
