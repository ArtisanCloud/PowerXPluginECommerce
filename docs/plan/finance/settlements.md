# 结算与分账 PRD

> 覆盖页面：`web-admin/app/pages/settlements.vue`、支付模块（`market/payment.vue`）、供应商/渠道/联盟结算视图。负责生成结算单、审批、分账、付款、对账，是资金流核心。

## 1. 目标
- 管理渠道/供应商/联盟/内部协作方的结算周期、结算单和分账明细，确保应收/应付准确、透明、可审计。

## 2. 信息架构
1. **结算总览**：KPI（待结算金额、已结算、逾期、分账进度）、按渠道/供应商/联盟分组。
2. **结算单列表**：
   - 字段：结算单号、对象（渠道/供应商/联盟）、账期、金额（总额、费用、调整、净额）、状态（草稿/审批/付款中/完成）、支付方式、负责人。
   - 筛选：对象、状态、账期、渠道、金额区间。
3. **结算单详情**：
   - 组成：订单/交易明细、费用（手续费、物流、营销）、税费、调整（补差、扣罚）、分账明细、付款记录。
   - 流程：生成 → 审批（财务/法务）→ 付款 → 对账 → 完成。
4. **分账管理**：
   - 分账规则：按订单或 SKU 分成比例/金额（与 `market/payment` PRD 一致），支持多方分成。
   - 分账执行：记录分账流水、状态、异常。

## 3. 功能
| 功能 | 描述 |
| --- | --- |
| 结算单生成 | 根据交易/订单/渠道规则按账期生成结算单，支持手动/自动 |
| 审批 | 多级审批（财务、法务、渠道负责人），审批记录与 SLA |
| 分账引擎 | 支持多方分成规则（比例、固定额、阶梯），与支付流水联动 |
| 调整 & 扣罚 | 手动调整、扣罚、费用补贴，记录原因 |
| 付款 | 生成付款指令，支持多种支付渠道、分期，记录凭证 |
| 对账 | 与银行/支付流水对账，确认完成 |
| 报表 | 结算报表、分账报表、渠道/供应商对账单 |
| 通知 | 结算单生成、审批结果、付款提醒 |

## 4. 数据 & API
- 表：`settlement_statements`、`settlement_items`、`settlement_adjustments`、`settlement_payments`、`settlement_split_rules`、`settlement_logs`。
- API：`GET/POST /api/settlements`、`POST /api/settlements/{id}/approve`、`POST /api/settlements/{id}/pay`、`GET /api/settlements/{id}/items`、`POST /api/settlements/{id}/adjust`。

## 5. 权限 & 审计
- 权限：`settlement.read`、`settlement.manage`、`settlement.approve`、`settlement.pay`、`settlement.report`。
- 审计：结算单生成、调整、审批、付款、分账操作，附上操作者、时间、理由。

## 6. KPI
| 指标 | 目标 |
| --- | --- |
| 结算准时率 | ≥ 95% |
| 分账准确率 | ≥ 99% |
| 审批周期 | ≤ 3 天 |
| 对账差异率 | < 1% |

## 7. 风险
- 数据源不一致导致差异；需与支付/订单/营销数据核对。
- 分账规则复杂；需测试、回滚机制。
- 欠款/逾期；需告警与信用控制。

## 8. Backlog
- 与 ERP/财务系统对接导出凭证。
- AI 风险预测（异常结算）。
- 自助结算 Portal（供应商/渠道查看结算单）。
