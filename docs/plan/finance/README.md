# 财税与结算模块规划总览

> 适用范围：`web-admin/app/pages/settlements.vue`、`web-admin/app/pages/tax.vue`、`web-admin/app/pages/payments/providers.vue`、`market/payment.vue` 以及涉及结算、分账、税务、对账的组件。财税与结算模块覆盖支付渠道管理、结算单、分账、税率配置、发票、对账、财务报表，是电商插件的资金流核心。

## 1. 文档目的
- 梳理财税/结算域的子模块：支付渠道、结算单/分账、税率与税则、对账、发票、财务报表；明确与营销、订单、履约、渠道的关系。
- 为 `docs/plan/finance` 下各 PRD 提供索引。

## 2. 当前页面覆盖
| 模块 | 前端路径 | 状态摘要 |
| --- | --- | --- |
| 结算与分账 | `settlements.vue` | 仅展示占位信息，需要结算单、账期、分账明细、审批 |
| 税率与税则 | `tax.vue` | 基础配置表单，缺乏多地区、多税种、规则引擎 |
| 支付渠道 | `payments/providers.vue` | 已有列表，但权限、API 配置、结算、风控需完善 |
| 支付单/交易流水 | `market/payment.vue` | 有概览页面，需详细交易详情、对账、分账、风控 |

## 3. 角色与价值
| 角色 | 核心诉求 |
| --- | --- |
| 财务/结算 | 管理账期、分账、对账、付款、发票 |
| 渠道运营 | 了解渠道费用、结算进度、分账策略 |
| 税务/法务 | 配置税率、税则、合规要求 |
| 营销/供应链 | 获取结算数据（返利、供应商款项） |

## 4. 功能规划概览
1. **支付渠道/Provider 管理**：配置 API、费率、结算周期、风控、分账规则（参考 `docs/plan/marketing/payments/README.md`）。
2. **结算单 & 分账**：生成结算单、审批、分账明细、付款状态，与订单、支付、供应商、渠道结算联动。
3. **税率与税则**：多地区税率、税类、税号、合规校验、发票设置。
4. **对账与报表**: 日/周/月对账、差异处理、财务报表、导出、审计。
5. **发票与税票**：开票、发票状态、税务合规。

## 5. 迭代路线
- Phase 1：支付渠道配置、结算单、税率配置、基础对账。
- Phase 2：分账引擎、自动对账、税则引擎、发票管理。
- Phase 3：多实体、多地区税务、自动申报、AI 风控。

## 6. 依赖
- 与营销支付 PRD（交易流水）、订单、供应商、渠道、商品、税务系统对接；数据安全和合规要求高。

## 7. 下一步
