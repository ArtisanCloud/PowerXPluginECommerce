# 履约任务与波次 PRD

> 覆盖尚未实现的履约任务/波次 UI，与库存调拨 (`transfers.md`)、仓库 (`warehouses.md`)、渠道订单 (`marketing/orders.md`) 联动。该模块负责拣货、包装、波次、派工、执行追踪。

## 1. 目标
- 将订单/调拨转化为可执行的履约任务，支持波次规划、任务分配、进度监控、异常记录。

## 2. 角色
| 角色 | 诉求 |
| --- | --- |
| 仓库主管 | 制定波次、分配任务、监控进度 |
| 拣货/包装人员 | 接受任务、扫描确认、上报异常 |
| 渠道运营 | 查看任务状态、确认发货计划 |

## 3. 信息架构
- 任务看板：按阶段（待分配、拣货中、包装中、待交付、完成、异常）展示任务卡片。
- 波次计划：波次号、仓库、时间、包含订单/调拨数、优先级、作业人员。
- 任务详情：SKU、数量、库位、拣货路径、设备、操作日志、异常。

## 4. 功能
| 功能 | 描述 |
| --- | --- |
| 自动波次 | 根据订单/调拨、规则（渠道、优先级、库存）生成波次，支持人工调整 |
| 任务派发 | 分配给拣货/包装/复核角色，支持移动端扫描 |
| 扫描执行 | 手持设备/移动端扫码确认，记录时间、人员 |
| 异常 | 库存不足、破损、找不到库位；生成异常工单 |
| KPI | 波次效率、任务按时完成率、异常率 |

## 5. 数据 & API
- 表：`fulfillment_waves`、`fulfillment_tasks`、`fulfillment_task_logs`、`fulfillment_exceptions`。
- API：`POST /api/fulfillment/waves`、`POST /api/fulfillment/tasks/{id}/complete`、`POST /api/fulfillment/exceptions`。

## 6. 权限 & 审计
- 权限：`fulfillment.task.read/manage`、`fulfillment.wave.read/manage`、`fulfillment.exception`。
- 审计：任务分派、状态变更、异常处理记录。

## 7. KPI
| 指标 | 目标 |
| --- | --- |
| 任务按时完成率 | ≥ 95% |
| 异常处理时效 | < 2 小时 |
| 波次效率 | 提升 ≥ 15% |

## 8. Backlog
- AI 波次推荐，基于库存和人员排班。
- 与手持设备/语音系统集成。
- 绩效统计（拣货员效率）。
