# 履约与物流模块规划总览

> 适用范围：`web-admin/app/pages/shipping/**`、订单/售后/渠道中的发货、运单、运费配置组件，以及未来需要的履约任务、波次、逆向物流。履约与物流模块覆盖承运商管理、运费模板、运单生成、轨迹监控、异常处理、履约任务协同，是连接订单、库存、调拨、售后、财务的关键环节。

## 1. 文档目的
- 梳理履约与物流域的子模块（承运商、运费模板、运单、物流任务、逆向物流），与库存/调拨/订单的边界。
- 为 `docs/plan/fulfillment` 下各 PRD 提供索引，指导后续实现。

## 2. 当前页面覆盖
| 模块 | 前端路径 | 状态摘要 |
| --- | --- | --- |
| 承运商管理 | `shipping/carriers.vue` | 有列表/表单雏形，缺乏服务配置、API 对接、KPI |
| 运费模板 | `shipping/templates.vue` | 基本表单，需支持区域分区、渠道策略、实验、版本 |
| 运单管理 | `shipping/waybills.vue` | 展示占位数据，需完整运单生命周期、轨迹、异常 |
| 配送任务/波次 | 暂无页面 | 需与调拨/仓库联动，规划拣货、波次、派车 |
| 逆向物流 | 售后模块 | 需在履约域统一管理退货运单、换货、补发 |

## 3. 角色与价值
| 角色 | 诉求 |
| --- | --- |
| 供应链/物流主管 | 管理承运商、运力、成本、异常 |
| 仓库/履约团队 | 获取运单、波次、任务、异常信息 |
| 渠道运营 | 配置渠道运费策略、选择承运商 |
| 客服/售后 | 查询物流状态、处理投诉、逆向物流 |
| 财务 | 运费结算、对账、分账 |

## 4. 功能规划概览
1. **承运商与服务管理**：承运商目录、服务范围、API 凭证、SLA、KPI。
2. **运费与计价**：运费模板、区域分区、实验、渠道策略、成本分析。
3. **运单与轨迹**：运单生成、打印、轨迹同步、异常处理、通知。
4. **履约任务/波次**：与库存/调拨的波次配合、派工、任务跟踪。
5. **逆向物流**：退货、换货、补发、逆向运单、费用结算，与客户运营的售后（`docs/plan/customer/returns-portal.md`）和支付退款（`docs/plan/marketing/payments.md`）打通，实现退货单→逆向运单→入库/报损→退款/补偿的闭环。

## 5. 迭代路线
- Phase 1：承运商管理、运费模板、运单生成/轨迹。
- Phase 2：波次、履约任务、异常处理、自动化通知。
- Phase 3：逆向物流、与第三方 TMS 深度集成、AI 承运商推荐。

## 6. 依赖
- 与库存/调拨（stock、transfers）、订单、售后、财务、营销（运费促销）紧密耦合。接口需统一。
