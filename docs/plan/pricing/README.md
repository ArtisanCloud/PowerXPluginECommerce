# 定价中心模块规划总览

> 适用范围：`web-admin/app/pages/pricing/**`（价目表、定价规则、合同价）及其相关组件、模态。定价中心是电商插件中连接商品、渠道、客户、结算的核心域，负责管理价目表、阶梯价、客户专属价、合同价，并与促销、结算、库存联动。

## 1. 文档目的
- 梳理定价中心包含的子模块、角色、能力矩阵。
- 明确价目表（价格手册）、规则引擎、合同价等职责与数据流。
- 指导后续在 `docs/plan/pricing` 下为具体功能（价目表、规则、合同价、阶梯价、客户专属价）编写 PRD。

## 2. 当前页面覆盖
| 模块 | 前端路径 | 状态概要 |
| --- | --- | --- |
| 价目表（价格手册） | `pricing/pricebooks.vue` | 列表与编辑 UI 初具雏形，需接入多币种、版本、导入导出 |
| 定价规则 & 阶梯价 | `pricing/rules.vue` | 条件编辑器示例，缺乏实际规则模型与冲突检测 |
| 合同价 / 协议价 | `pricing/contracts.vue` | 合同档案页面，需要审批流、客户绑定、价目引用 |
| 价格概览 | `pricing/index.vue` | KPI 卡与快捷入口，需接入真实数据 |

## 3. 角色与价值
| 角色 | 核心诉求 |
| --- | --- |
| 定价经理 | 维护价目表、版本、审批，控制不同渠道/客户价格策略 |
| 销售/渠道运营 | 查询价格手册、客户专属价，发起特批或合同价 |
| 财务/结算 | 获取结算价、折扣信息，核对账单 |
| 客服/售后 | 查价、处理价格争议或补差 |
| 技术/数据 | 对接定价 API，确保与前台/第三方同步一致 |

## 4. 功能规划概览
1. **价格手册（价目表 / Pricebook）**
   - 支持多币种、多渠道、版本管理；记录基准价、建议零售价、渠道价、最小/最大价。
   - 导入导出、批量更新、审批流程。
   - 可引用到 SKU、类目、渠道、客户组。
2. **定价规则 / 阶梯价**
   - 条件（客户组、渠道、时间、订单量、SKU 属性）+ 动作（折扣、固定价、价差）。
   - 阶梯价、批量折扣、限时价格；支持冲突检测、优先级、模拟。
3. **客户专属价 / 合同价**
   - 针对客户或客户组的特定价格；可来自协议合同或特批。
   - 合同管理：条款、有效期、审批、通知、价目引用。
4. **审批与特批**
   - 超出规则/价目限制时，自动触发特批流程（销售 → 定价经理 → 财务）。
5. **对外 API / 同步**
   - 提供价格查询 API 给前台、渠道平台；支持缓存、版本号。
   - 记录价格变更日志，通知库存/渠道/营销。
6. **优惠券与权益抵扣**
   - 优惠券在订单结算层复算并参与应付价计算，支付成功后核销；与促销/积分共享叠加与排他语义。
   - 执行细则见：`docs/plan/pricing/coupons.md` 第 9 章“完整优惠券机制实施计划（对齐执行版）”。

## 5. 迭代路线建议
- **Phase 1**：价目表主数据 + 多币种 + 基本导入导出 + 手动审批。
- **Phase 2**：定价规则引擎（阶梯价、客户价）、冲突检测、模拟器。
- **Phase 3**: 合同价、审批流、通知、与采购/结算联动。
- **Phase 4**: AI/推荐定价、弹性定价、渠道实时同步、A/B 测试。

## 6. 依赖与对齐
- 与商品 SKU、渠道、客户域共享主数据。
- 定价输出需供订单、结算、促销模块消费；与 `pricing` API、缓存机制对齐。
- 审批、合同、导入导出等能力可复用 PowerX 底座组件。
