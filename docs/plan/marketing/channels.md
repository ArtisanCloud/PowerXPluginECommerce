# 渠道运营 PRD

> 覆盖页面：`web-admin/app/pages/market/channels.vue`、`web-admin/app/pages/channels/**`（渠道列表、授权、上架发布、SKU 映射）。该模块负责统一管理线上/线下渠道、店铺、授权状态、发布计划，是商品、定价、库存、营销之间的枢纽。

## 1. 背景与目标
- 电商插件需要连接多个销售渠道（自营站、京东、天猫、拼多多、线下门店等），统一管理授权、SKU 映射、上架计划、渠道 KPI。现有页面提供静态列表，需要补齐完整运营能力。

**目标**
1. 构建“渠道/店铺”主数据：状态、凭证、负责人、可售品类、定价策略、配送/仓储配置。
2. 提供 SKU 映射、上架发布、渠道定价、库存同步能力，确保跨渠道一致性。
3. 监控渠道 KPI（GMV、订单、库存、异常），支持告警、操作历史、审计。

## 2. 角色
| 角色 | 诉求 |
| --- | --- |
| 渠道运营 | 管理渠道授权、上架、促销计划，监控健康度 |
| 商品/定价团队 | 了解渠道可售 SKU、定价、库存策略 |
| 供应链 | 根据渠道需求准备库存、履约方案 |
| 财务/结算 | 管理渠道手续费、账期、对账 |

## 3. 信息架构
1. **渠道/店铺列表**
   - 字段：渠道类型、店铺名称、状态（待授权/已授权/暂停）、负责人、绑定仓库、定价策略、最近同步时间、关键指标（GMV、订单、库存覆盖率）。
   - 筛选：类型、状态、负责人、区域、同步状态。
   - 操作：查看详情、授权/刷新凭证、暂停、同步、进入上架发布。
2. **渠道详情**
   - 基本信息：渠道类型、店铺 ID、授权凭证、回调 URL、联系人。
   - 配置：定价策略（引用 pricebook）、库存/仓库绑定、物流模板、结算/手续费、发票、客服策略。
   - SKU 映射：本地 SKU ↔ 渠道 SKU，包含属性映射、状态、同步历史。
   - 上架任务：版本、状态、错误、负责人、计划时间。
   - KPI：GMV、订单、转化率、退货率、库存周转、异常警报。
3. **SKU 映射工作台**
   - 支持批量映射、属性/类目映射规则、自动匹配建议、异常检查（缺图/缺属性）。
4. **上架发布中心**
   - 构建发布计划，选择 SKU、渠道、上线时间、定价/库存策略，生成任务，查看日志。

## 4. 功能清单
| 功能 | 描述 |
| --- | --- |
| 渠道/店铺注册 | 手动或通过 API 导入渠道；管理授权流程、凭证刷新、审批 |
| SKU 映射 | 自动/手动映射、差异检测、映射规则模板（属性/类目） |
| 上架/下架计划 | 选择 SKU、渠道、时间、版本；支持灰度、回滚、日志 |
| 渠道定价策略 | 引用 pricebook/规则，支持渠道特价/促销同步 |
| 库存同步 | 配置库存来源（全局/仓库/门店）、同步频率、异常告警 |
| 渠道 KPI & 告警 | GMV、订单、库存、退货、授权状态监控；自定义阈值告警 |
| 操作历史 & 审计 | 记录授权、映射、上架、暂停等操作，支持回溯 |
| 渠道任务协同 | 与运维/客服/商品团队协同处理渠道任务（异常、整改） |

## 5. 关键流程
1. **渠道接入**：创建渠道 → 授权 → 填写配置（定价、库存、物流）→ 验证 → 上线。
2. **SKU 映射**：导入 SKU → 自动匹配/手动映射 → 校验属性/类目 → 保存并同步。
3. **上架发布**：选择渠道、SKU、价目、库存策略 → 设置时间 → 生成任务 → 监控日志。
4. **异常处理**：监控告警（库存不足、授权失效、SKU 异常）→ 任务协同 → 记录处理结果。

## 6. 数据 & API
- 表：`channels`、`channel_stores`、`channel_configs`、`channel_sku_mappings`、`channel_publish_tasks`、`channel_metrics`、`channel_audit_logs`。
- API：
  - `GET/POST /api/channels`、`PATCH /api/channels/{id}`、`POST /api/channels/{id}/authorize`。
  - `GET/POST /api/channels/{id}/sku-mappings`、`POST /api/channels/{id}/publish`。
  - `GET /api/channels/{id}/metrics`、`POST /api/channels/{id}/sync`。

## 7. 权限与审计
- 权限：`channel.read`、`channel.manage`、`channel.publish`、`channel.sku`, `channel.metrics`。
- 审计：授权、映射、上架、配置变更等记录 `admin_console_audit_events`；对于第三方 API 调用保留请求日志。

## 8. KPI
| 指标 | 目标 |
| --- | --- |
| 授权/配置成功率 | ≥ 99% |
| SKU 映射准确率 | ≥ 98% |
| 上架任务成功率 | ≥ 97% |
| 异常响应时间 | < 30 min |

## 9. 风险
- 渠道授权/凭证过期导致同步失败；需要监控和自动提醒。
- SKU 映射不一致导致下单失败；需有校验与模拟。
- 渠道 API 限额/延迟，需排队和重试策略。
