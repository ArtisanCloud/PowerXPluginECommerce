# 渠道订单管理 PRD

> 覆盖页面：`web-admin/app/pages/market/orders.vue`，并与 `channels/**`、`inventory/**`、`customer/returns/**`、`settlements.vue` 等模块联动。该模块聚焦渠道订单（自营站、第三方平台、线下门店）在后台的监控、处理、异常协同。

## 1. 背景与目标
- 当前 `market/orders.vue` 展示基本订单列表，但缺乏统一的渠道订单看板、状态流转、异常处理、与客服/仓储协同机制。

**目标**
1. 提供渠道订单总览与列表：多渠道订单在一个界面中查看、筛选、监控 KPI（GMV、订单数、履约进度、异常率）。
2. 支持订单详情、状态流（待付款、待发货、履约中、售后中、完成）、与库存/物流/客服联动。
3. 处理异常订单（风控、库存不足、物流失败、授权失效），记录操作与审计。

## 2. 角色
| 角色 | 诉求 |
| --- | --- |
| 渠道运营 | 监控各渠道订单、执行手动操作（发货、取消、补偿） |
| 客服/售后 | 处理客户咨询、售后申请，与订单联动 |
| 仓储/物流 | 查看履约状态、打印面单、处理异常 |
| 财务 | 关注应收/退款、结算进度 |
| 风控 | 审核高风险订单 |

## 3. 信息架构
1. **订单总览**
   - KPI：订单数、GMV、转化率、履约完成率、异常订单、退款率、**分账订单占比**。
   - 筛选：渠道、店铺、状态、时间、SKU、客户分群、负责人、**订单类型/履约模式**。
2. **订单列表**
   - 字段：订单号、渠道、店铺、客户、SKU/数量、金额（原价/折扣/实付）、状态、支付方式、来源、**订单类型（自营/渠道/B2B/分账等）、履约模式（仓发/门店/直发）**、创建时间、负责人。
   - 操作：查看、发货、取消、重推、标记异常、进入售后。
3. **订单详情**
   - 基础信息、商品、价格明细、折扣、支付流水、配送地址、物流信息、备注、操作日志。
   - 状态时间线：每个节点（下单、付款、发货、签收、售后）及操作人。
   - 关联：促销/券/旅程 ID、供应商/仓库、客服/风控记录、**售后单（`customer/returns`）与退款单（支付模块）**。
4. **异常/任务面板**
   - 异常类型（库存不足、支付失败、地址异常、风控、售后）→ 任务列表，分配给对应团队。
5. **批量操作**
   - 批量发货、批量取消、批量重推渠道、导出。

## 4. 功能清单
| 功能 | 描述 |
| --- | --- |
| 多渠道订单聚合 | 从各渠道同步订单，统一展示，标注来源与同步状态 |
| 状态管理 | 订单状态机、手动/自动状态更新、重试、日志 |
| 发货与物流 | 绑定仓库/物流模板、生成面单、推送物流信息 |
| 风控 | 高风险订单审核、自动/人工阻断、记录风险标签 |
| 异常处理 | 异常分类、任务分配、协同（客服/仓储/渠道） |
| 报表导出 | 多维度导出 Excel/CSV，支持 API 接入 |
| 通知 | 关键节点告警（渠道同步失败、发货延迟、异常订单） |

## 5. 流程
1. **订单同步**：渠道 → API/批处理 → 系统中落地；记录同步日志、错误。
2. **履约处理**：匹配库存 → 指派仓库 → 生成发货任务 → 更新状态。
3. **异常处理**：检测到库存不足/支付失败等 → 生成任务/告警 → 协作处理 → 记录结果。
4. **售后联动**：进入售后流程（`customer/returns`），变更订单状态、退款等。

## 6. 数据 & API
- 表：`channel_orders`、`channel_order_items`、`channel_order_logs`、`channel_order_tasks`、`channel_order_metrics`。
- API：
  - `GET /api/channel/orders`、`POST /api/channel/orders/sync`、`PATCH /api/channel/orders/{id}`。
  - `POST /api/channel/orders/{id}/ship`、`POST /api/channel/orders/{id}/cancel`、`POST /api/channel/orders/{id}/retry`。

## 7. 权限 & 审计
- 权限：`channel.orders.read`、`channel.orders.manage`、`channel.orders.ship`、`channel.orders.risk`、`channel.orders.export`。
- 审计：状态变更、发货、取消、异常处理记录 `admin_console_audit_events`。

## 8. KPI
| 指标 | 目标 |
| --- | --- |
| 订单同步成功率 | ≥ 99% |
| 异常处理时效 | < 1 小时 |
| 履约准时率 | ≥ 95% |
| 退款处理时效 | < 48h |

## 9. 风险
- 渠道同步失败或延迟导致信息不一致；需重试机制与告警。
- 人工操作错误影响状态，需权限和确认机制。
- 数据量大时性能挑战，需要分页/异步处理。
