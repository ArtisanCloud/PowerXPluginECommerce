# 增长分析 PRD

> 覆盖页面：`web-admin/app/pages/market/analytics.vue`、`customer/analytics/**`（funnel、cohort、segmentation）及新增的数据可视化视图。该模块提供增长指标、漏斗、渠道/活动 ROI、实验分析，为营销、产品、运营提供决策支持。

## 1. 背景与目标
- 现有页面仅展示静态图表，需要真实数据接入、可交互分析、目标管理、告警、AB 测试结果，才能指导营销增长策略。

**目标**
1. 构建统一的增长看板，涵盖 GMV、订单、客单、留存、渠道 ROI、活动贡献、漏斗（浏览→加购→下单→支付）。
2. 支持分群分析、 cohort、漏斗、路径分析；提供自定义指标与报表导出。
3. 与营销活动、旅程、促销联动，支持效果归因、A/B 实验统计。

## 2. 角色
| 角色 | 诉求 |
| --- | --- |
| 营销/增长 | 查看活动、渠道、旅程的产出，优化策略 |
| 产品 | 观察用户行为漏斗、功能使用、留存 |
| 数据分析 | 配置指标、模型、实验、告警 |
| 运营/管理层 | 关注 KPI、目标完成度、即时告警 |

## 3. 信息架构
1. **增长总览看板**
   - KPI 卡：GMV、订单、客单、流量、转化率、留存、活跃客户、券使用、旅程触达。
   - 目标 vs 实际：OKR、预算、趋势、告警。
2. **漏斗 & 路径**
   - 可配置漏斗阶段、过滤条件（渠道、活动、分群、设备）；显示转化率、流失原因、Top path 分析。
3. **渠道/活动分析**
   - 按渠道/店铺/活动展示 GMV、订单、ROI、库存影响、返利；可 drill-down。
4. **分群 & Cohort**
   - 支持动态分群、 cohort 留存、LTV、ARPU、行为对比。
5. **实验 & A/B**
   - 展示实验列表、目标、指标、显著性；支持旅程/活动/定价实验。
6. **报表与订阅**
   - 导出 CSV/PDF；支持订阅到邮件/Slack；自定义告警（阈值、异常检测）。

## 4. 功能清单
| 功能 | 描述 |
| --- | --- |
| 指标库 | 定义指标、维度、计算逻辑（基于数据仓库/实时流） |
| 看板配置 | 拖拽式配置看板（组件库：KPI 卡、图表、表格、漏斗、地图） |
| 筛选/钻取 | 全局筛选（时间、渠道、活动、客户分群、SKU）；支持 drill-down、对比 |
| 归因 | 与活动/旅程/促销关联，提供多触点归因模型（线性、末次等） |
| 实验分析 | 自动计算实验显著性、胜出方案；支持导出、通知 |
| 告警 & 订阅 | 指标阈值、异常波动告警；定时发送报告 |
| 数据接口 | 支持通过 API/SDK 获取部分指标，供第三方 BI 使用 |

## 5. 数据来源与技术
- 实时数据：订单、支付、旅程触达、券核销、渠道事件（通过流式管道）。
- 离线数据：数据仓库中的聚合表（每日/每小时），用于 cohort、LTV、ROI。
- 数据模型：`growth_metrics`、`growth_dashboards`、`growth_funnels`、`growth_experiments`、`growth_alerts`。
- API：`GET /api/growth/kpi`、`GET /api/growth/funnel`、`GET /api/growth/experiments`、`POST /api/growth/alerts`。

## 6. 流程
1. 配置看板 → 选择指标组件 → 设置过滤条件 → 保存为模板 → 分享或订阅。
2. 运行活动/旅程 → 数据自动进入分析模块 → 归因和漏斗展示效果。
3. 当指标异常 → 触发告警 → 分析原因（渠道/活动/库存问题）。

## 7. 权限 & 审计
- 权限：`growth.analytics.read`、`growth.analytics.manage`、`growth.analytics.dashboard`, `growth.analytics.alerts`。
- 审计：看板更改、指标定义变更、告警规则修改记录。
- 数据安全：敏感指标可脱敏或限制访问（如利润、成本）。

## 8. KPI
| 指标 | 目标 |
| --- | --- |
| 数据更新延迟 | 实时流 < 5 分钟；离线 < 2 小时 |
| 看板加载时间 | < 2 秒 |
| 告警准确率 | ≥ 90% |
| 用户留存 | ≥ 70% 月活营销/运营用户 |

## 9. 风险
- 数据质量问题影响决策，需数据校验、回放机制。
- 自定义指标过多可能导致性能问题；需要缓存和权限控制。
- 归因模型复杂，需透明可配置。

## 10. Backlog
- AI/ML 驱动的异常检测、预测。
- Looker/Tableau 等 BI 集成。
- 语音或自然语言查询指标。
- KPI 与 OKR 联动（自动更新进度）。
