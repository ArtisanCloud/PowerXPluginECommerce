# 营销活动 / 运营控制台 PRD

> 覆盖页面：`web-admin/app/pages/market/marketing.vue` 以及后续需要新增的活动创建、审批、执行、监控视图。该模块用于统一管理营销活动（线上/线下、单渠道/多渠道），协调促销、资产（券/卡）、渠道投放、预算与效果。

## 1. 背景与目标
- 目前营销页面仅展示静态卡片，需要一个完整的活动管理系统：创建、审批、执行、监控、复盘。
- 活动需要调度定价中心的促销规则、优惠券、礼品卡、渠道投放，与客户旅程、分析联动。

**目标**
1. 构建活动生命周期：需求→创建→审批→执行→监控→复盘/归档。
2. 活动配置支持多渠道、多个营销资产、预算/成本控制、内容/素材管理。
3. 提供实时监控面板（GMV、订单、ROI、预算消耗、异常告警）。

## 2. 角色
| 角色 | 诉求 |
| --- | --- |
| 营销经理 | 创建活动、分配资源、查看执行状态 |
| 渠道运营 | 执行渠道投放、素材管理 |
| 定价/资产团队 | 提供促销、券、卡等资产，审核价格策略 |
| 财务/法务 | 审核预算、合同、合规 |
| 客户运营 | 联动旅程、分群推送 |

## 3. 信息架构
1. **活动列表/看板**
   - 显示活动卡片：名称、类型（拉新/促活/复购/大促）、渠道、时间、状态、目标 KPI、负责人、预算。
   - 看板视图（需求、审批、执行、完成、复盘）。
2. **活动详情**
   - 基本信息：目标、类型、时间、渠道、客户分群、预算、审批链。
   - 策略配置：关联的促销规则、优惠券批次、礼品卡、任务、旅程触达。
   - 渠道投放：渠道/店铺、素材、上线计划、审批、状态。
   - 内容/素材：海报、落地页、短信/邮件模板、社交文案。
   - 预算与成本：预算分配、实际消耗、供应商费用、返利。
   - KPI & 实时数据：GMV、订单、转化率、ROI、领券/核销、渠道表现。
   - 风险与问题：异常告警、SLA、任务协同。
   - 复盘：目标 vs 实际、亮点/问题、TODO。
3. **任务协同**
   - 活动下拆分任务（素材、渠道、客服、开发、法务等），支持进度、负责人、截止日期。

## 4. 功能清单
| 功能 | 描述 |
| --- | --- |
| 活动模板 | 按场景（拉新、节日、会员日）预置模板，含目标/KPI/资产建议 |
| 活动创建 & 审批 | 配置基础信息、资产、渠道、预算；走审批流（营销→定价→法务→财务） |
| 资产联动 | 绑定促销规则、券/卡、旅程任务；在活动中统一管理库存、上限 |
| 渠道投放 | 生成渠道发布任务，记录状态、日志、异常 |
| 预算 & 成本 | 设置预算上限、分配渠道；实时监控消耗，超限预警 |
| KPI 监控 | 可视化仪表板 + 实时数据；支持自定义指标、告警规则 |
| 复盘导出 | 活动结束后导出报告，包括目标完成度、渠道表现、资产使用、ROI |
| 活动日历 | 日历视图，查看当月活动，避免冲突 |

## 5. 流程
1. **活动创建**：选择模板 → 填写目标/时间/分群/预算 → 关联资产 → 提交审批。
2. **执行阶段**：审批通过后生成渠道任务、资产发行、旅程触发；实时监控指标、处理异常。
3. **复盘阶段**：活动结束后自动汇总数据，生成报告；记录经验和改进项。

## 6. 数据 & API
- 表：`marketing_campaigns`、`campaign_assets`、`campaign_channels`、`campaign_tasks`、`campaign_metrics`、`campaign_audit_logs`。
- API：
  - `GET/POST /api/marketing/campaigns`、`PATCH /api/marketing/campaigns/{id}`、`POST /api/marketing/campaigns/{id}/submit`、`POST /api/marketing/campaigns/{id}/approve`。
  - `GET /api/marketing/campaigns/{id}/metrics`、`POST /api/marketing/campaigns/{id}/sync`。
  - `POST /api/marketing/campaigns/{id}/tasks`、`POST /api/marketing/campaigns/{id}/assets`。

## 7. 权限 & 审计
- 权限：`campaign.read`、`campaign.manage`、`campaign.approval`、`campaign.budget`、`campaign.metrics`。
- 审计：活动创建、修改、审批、资产/渠道变更、预算调整、发布/暂停等记录。

## 8. KPI
| 指标 | 目标 |
| --- | --- |
| 活动审批周期 | ≤ 3 天 |
| 活动按期上线率 | ≥ 95% |
| KPI 达成率 | 80% 活动达到既定目标 |
| 异常处理响应 | < 30 min |

## 9. 风险
- 多方协作复杂，需清晰的任务分配与通知。
- 活动过多导致资源冲突，需要日历与冲突检测。
- 数据延迟影响决策，需实时数据管道。

## 10. Backlog
- 自动推荐活动策略/模板。
- AI 生成文案/素材建议。
- 活动归因引擎，与增长分析深度结合。
- 外部渠道 API 对接（广告平台、社交平台）。
