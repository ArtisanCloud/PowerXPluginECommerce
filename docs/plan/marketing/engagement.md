# 互动资产 & 任务协同 PRD

> 覆盖页面：计划新增的 `web-admin/app/pages/market/engagement.vue`、现有 `market/marketing.vue` 中的任务组件、`marketplace`/`operations` 目录下的互动型组件。该模块负责管理营销素材、互动任务、社交/联盟运营、客服协同，确保活动执行落地。

## 1. 背景与目标
- 活动执行牵涉素材设计、内容发布、社交互动、联盟/分销协同、客服支持。目前缺乏统一的资产库与任务协同机制。

**目标**
1. 建立营销素材/互动资产中心（文案、海报、落地页、短链、视频），支持版本管理、审批、渠道适配。
2. 通过任务协同看板，协调活动执行所需的跨部门任务（素材、上线、客服、供应链），提供提醒、SLA、审计。
3. 管理互动渠道（社交、社区、联盟、直播等），沉淀内容与互动记录，串联到活动与旅程。

## 2. 角色
| 角色 | 诉求 |
| --- | --- |
| 营销/内容团队 | 管理素材、文案、审批流程 |
| 渠道运营 | 获取最新素材、发布到渠道、跟踪反馈 |
| 客服/社区 | 了解活动、热点，回复用户、记录问题 |
| 设计/供应商 | 上传素材、接收任务、反馈进度 |
| 联盟/分销 | 获取推广素材、跟踪绩效 |

## 3. 信息架构
1. **素材资产库**
   - 分类：图片、视频、文案、模板、Landing Page、短链、直播脚本。
   - 元数据：活动、渠道、语言、版本、审批状态、使用记录。
   - 操作：上传、版本、引用、渠道适配、一键推送、到期提醒。
2. **互动/任务看板**
   - 看板列（需求、进行中、待审核、完成、阻塞）；卡片记录任务类型、负责人、截止时间、关联活动/渠道。
   - 支持子任务、评论、附件、审计。
3. **社交/联盟面板**
   - 记录社交账号、社区、联盟合作伙伴；管理素材投放、内容排期、互动数据。
   - 提供简易 CRM：消息、反馈、FAQ、工单。
4. **内容发布计划**
   - 日历视图，展示各渠道/社交平台的内容发布安排、状态。

## 4. 功能清单
| 功能 | 描述 |
| --- | --- |
| 素材上传 & 审批 | 与媒体中心对接（PowerX Media Storage），添加营销字段、审批流程 |
| 渠道适配 | 针对不同渠道/社交平台生成适配版本（尺寸、文案、标签）|
| 资产引用 | 活动、旅程、渠道任务可直接引用素材，记录使用情况 |
| 任务协同 | 创建任务、分配、SLA、提醒、评论、附件、操作日志 |
| 日历 & 排期 | 可视化查看活动、内容、直播、社交排期，避免冲突 |
| 互动记录 | 记录社交反馈、用户评论、客服热点，输出洞察 |
| 联盟素材中心 | 供分销/联盟伙伴下载素材、获取跟踪链接 |
| KPI | 素材使用率、任务按时完成率、社交互动指标 |

## 5. 流程
1. 素材需求提出 → 设计/供应商上传 → 审批 → 入库 → 活动/渠道引用。
2. 活动创建后自动生成任务模板（素材、内容、客服 FAQ 等）→ 分配 → 跟踪进度 → 记录完成。
3. 互动反馈（社交/客服）→ 归档 → 推送给活动/产品/客服团队。

## 6. 数据 & API
- 表：`engagement_assets`、`engagement_asset_versions`、`engagement_tasks`、`engagement_task_logs`、`engagement_channels`、`engagement_calendar`、`engagement_feedback`。
- API：`GET/POST /api/engagement/assets`、`POST /api/engagement/tasks`、`PATCH /api/engagement/tasks/{id}`、`GET /api/engagement/calendar`、`POST /api/engagement/feedback`。

## 7. 权限 & 审计
- 权限：`engagement.asset.read/manage`、`engagement.task.read/manage`、`engagement.calendar`、`engagement.feedback`。
- 审计：素材变更、审批、任务状态变化、反馈处理记录。

## 8. KPI
| 指标 | 目标 |
| --- | --- |
| 素材复用率 | ≥ 70% |
| 任务按时完成率 | ≥ 90% |
| 反馈处理时间 | < 24h |
| 社交互动响应率 | ≥ 95% |

## 9. 风险
- 素材版权/合规风险，需要审批与权限控制。
- 任务协同跨部门，需要通知、权限、责任清晰。
- 数据分散（社交平台 API），需统一采集与权限管理。

## 10. Backlog
- 与第三方协同工具（Jira、Asana、Slack）集成。
- AI 生成文案/素材建议。
- 联盟推广链接管理、绩效追踪。
- 互动洞察（情绪分析、热点提醒）。
