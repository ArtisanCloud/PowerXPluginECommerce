# 营销增长模块规划总览

> 适用范围：`web-admin/app/pages/market/**`（channels、marketing、promotions、analytics、orders、payment）、客户运营中的分析/积分兑换页面、以及后续需新增的旅程编排、A/B 实验、互动自动化等能力。营销增长模块覆盖渠道运营、促销活动、用户触达、增长分析、互动工具，是连接定价、客户、渠道的运营枢纽。

## 1. 文档目的
- 梳理营销增长域下已有页面与能力缺口，为每个子模块输出 PRD 提供索引。
- 明确角色分工、数据依赖、与定价/客户/商品/渠道模块的联动方式。
- 提供整体迭代路线，方便拆解旅程编排、互动自动化、增长分析等任务。

## 2. 当前页面覆盖
| 模块 | 前端路径 | 状态摘要 |
| --- | --- | --- |
| 渠道概览 | `market/channels.vue`、`channels/**` | 渠道列表 + 授权状态 UI，缺少多店铺管理与实时同步 |
| 营销活动 | `market/marketing.vue` | 活动卡片/任务列表雏形，需补齐活动配置、审批、执行状态 |
| 促销规则 | `market/promotions.vue` | 已有卡片展示，与定价中心 PRD 联动，需要模板化配置、渠道投放、监控 |
| 营销分析 | `market/analytics.vue`、`customer/analytics/**` | 漏斗、分群等静态展示，需要真实指标、AB 实验、增长目标 |
| 渠道订单/支付 | `market/orders.vue`、`market/payment.vue` | 展示渠道订单与支付概况，需引入 KPI、异常监控 |
| 优惠券/礼品卡 | `customer/membership/points/mall.vue`、定价模块 PRD | 当前在积分商城，计划迁移到独立营销资产中心 |

## 3. 角色与价值
| 角色 | 核心诉求 |
| --- | --- |
| 营销/增长经理 | 设计活动、旅程，拉新促活，查看效果与归因 |
| 渠道运营 | 维护渠道授权、投放计划、SKU 映射与渠道定价 |
| CRM/客户运营 | 利用分群、旅程向客户触达，组合优惠券/积分/礼品卡 |
| 数据分析 | 监控漏斗、转化、ROI、预测增长策略 |
| 财务/合规 | 控制预算、审核活动成本、跟踪返利 |

## 4. 功能规划概览
1. **渠道运营**：渠道授权、店铺管理、SKU 映射、上架发布、渠道 KPI；与商品/定价/库存同步。
2. **促销与营销资产**：促销规则、优惠券、礼品卡、权益包、任务；与定价中心联动，提供模板、审批、库存控制。
3. **营销旅程 & 自动化**：基于客户事件/分群的触达流程，支持触发条件、动作（发券、推送、积分）、节奏控制、A/B 实验。
4. **增长分析**: 漏斗、渠道 ROI、活动成效、用户路径、实验结果；支持目标设定与告警。
5. **互动/任务**: 各渠道的活动素材管理、内容发布、社交互动、联盟运营。

## 5. 迭代建议
- Phase 1：夯实营销资产（促销、券、卡）与渠道运营，打通定价/渠道联动。
- Phase 2：上线旅程编排、自动化触达、分群联动（与客户模块合作）。
- Phase 3：增长实验、A/B 测试、实时归因、智能推荐。
- Phase 4：跨渠道协同（线下门店/第三方平台）、AI 增长策略、自动预算分配。

## 6. 依赖与对齐
- 与定价中心共享价目表/促销规则；与客户模块共享分群、旅程、积分；与商品/渠道共享 SKU/渠道关系；与支付/结算统筹预算和返利。
- 需要统一的营销资产 API（促销、券、礼品卡、任务）供前台、第三方调用。

## 7. 下一步
- 为渠道运营、营销活动、旅程编排、增长分析、互动资产等子模块分别撰写 PRD。
- 梳理与客户/定价的联动接口（分群、价目、优惠叠加策略）。
- 规划营销资产中心（优惠券、礼品卡、权益包）在营销目录下的迁移步骤。
