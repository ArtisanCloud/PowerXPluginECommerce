# 货币与小数精度 PRD

> 覆盖 `web-admin/app/pages/settings/currency.vue`，负责默认货币、多币种、精度、汇率、展示规则、权限。

## 1. 目标
- 管理系统的货币设置：默认货币、多币种支持、精度（小数位）、汇率来源、展示格式、权限控制，与定价/财务/结算联动。

## 2. 信息架构
- 货币列表：货币代码、名称、符号、精度、小数舍入、汇率、状态。
- 默认货币 & 备选货币：配置默认，设置允许使用的币种，指定汇率来源。
- 精度与格式：每种货币可设置显示格式、四舍五入规则、财务精度。
- 权限/可见性：哪些用户/渠道/区域可使用某币种。

## 3. 功能
| 功能 | 描述 |
| --- | --- |
| 货币管理 | 添加/编辑/启用/停用货币，配置符号、精度、格式 |
| 默认货币 | 设置全局默认货币，影响价格显示、报表、结算 |
| 汇率同步 | 从外部汇率 API（ECB、Fixer）自动同步；支持手动输入、历史记录 |
| 精度规则 | 设定财务精度、展示精度、舍入规则、千分位 |
| 权限 | 控制哪些渠道/国家可用某币种；配置多币种可售策略 |
| 日志 | 记录变更、审批、错误 |

## 4. 数据 & API
- 表：`settings_currencies`、`settings_currency_rates`、`settings_currency_logs`。
- API：`GET/POST /api/settings/currencies`、`PATCH /api/settings/currencies/{code}`、`POST /api/settings/currencies/sync`。

## 5. 权限 & 审计
- 权限：`settings.currency.manage`、`settings.currency.view`。
- 审计：货币新增、变更、汇率同步、默认货币切换。

## 6. KPI
| 指标 | 目标 |
| --- | --- |
| 汇率更新延迟 | < 1h |
| 精度错误率 | < 0.1% |

## 7. Backlog
- 多币种价格显示（客户可选择显示单位）。
- 多租户/区域不同默认货币。
- AI 提醒汇率波动。
