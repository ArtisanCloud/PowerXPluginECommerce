# 系统设置模块规划总览

> 适用范围：`web-admin/app/pages/settings/**`（currency, orders, roles/permissions 等）以及贯穿全局的配置项（租户设置、审计、风控、门户配置）。系统设置模块为插件提供统一的配置与治理能力，包括全局参数、权限、租户/环境、风控策略、审计、品牌化等。

## 1. 文档目的
- 梳理系统设置域下的子模块：订单/流程配置、货币与精度、权限与角色、租户设置、品牌/门户、审计风控等。
- 为 `docs/plan/settings` 下各 PRD 提供索引，指引开发与治理需求。

## 2. 当前页面覆盖
| 模块 | 前端路径 | 状态摘要 |
| --- | --- | --- |
| 订单与流程配置 | `settings/orders.vue` | 显示基础配置项，缺乏工作流与审计 |
| 货币与小数精度 | `settings/currency.vue` | 可设定货币、精度，需多币种、汇率、权限 |
| 权限与角色 | `settings/roles.vue` | 列表与操作日志，需细粒度权限、审批、模板 |
| 租户/品牌设置 | 暂无页面 | 需要租户信息、品牌化、门户配置 |
| 审计/风控设置 | 依赖后台 | 需暴露审计策略、告警、接口 |

## 3. 角色与价值
| 角色 | 诉求 |
| --- | --- |
| 系统管理员 | 管理全局设置、租户信息、审计、风控 |
| 运维/安全 | 控制权限、审计、日志、风控策略 |
| 财务 | 货币、汇率、税率（与财税模块协同） |
| 业务负责人 | 订单流程、审批策略、品牌样式配置 |

## 4. 功能规划概览
1. **订单与流程配置**：状态机、审批、SLA、通知模板、售后策略。
2. **货币与精度**：默认货币、多币种、精度、汇率、展示规则。
3. **权限与角色**：RBAC、权限模板、审批、操作日志。
4. **租户与品牌**：租户信息、域名、品牌（logo、颜色）、门户设置。
5. **审计与风控策略**：审计级别、日志导出、风控规则、告警渠道。
6. **开发者设置**：API Key、Webhooks、Connector 配置（与渠道/履约联动）。

## 5. 迭代路线
- Phase 1：订单配置、货币/精度、权限/角色基础能力。
- Phase 2：租户/品牌化、审计/风控策略、API 设置。
- Phase 3：模板化配置、环境管理（Dev/Stage/Prod）、合规报告。

## 6. 依赖
- 与订单、财税、渠道、履约等模块共享配置；权限、审计、风控需与后端系统协同。

## 7. 下一步
- 在 `docs/plan/settings` 中为订单配置、货币/精度、权限/角色、租户/品牌、审计风控、API 开发者等子模块撰写 PRD。
