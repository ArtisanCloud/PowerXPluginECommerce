# 数据与增长分析模块规划总览

> 适用范围：`web-admin/app/pages/reports/**`（sales, products, conversion）、`web-admin/app/pages/market/analytics.vue`、`customer/analytics/**` 以及计划中的指标看板、漏斗、实验、归因等产品。该模块负责统一的 BI/增长分析、指标定义、可视化、告警、实验分析，为运营、营销、产品、管理层提供决策依据。

## 1. 文档目的
- 整理增长分析域的子模块：指标定义与看板、漏斗/路径、分群分析、实验/A-B 测试、归因、报表导出、告警等。
- 与营销、客户、商品、渠道、财务等模块对齐数据来源和依赖，为 `docs/plan/analytics` 下各 PRD 提供索引。

## 2. 当前页面覆盖
| 模块 | 前端路径 | 状态摘要 |
| --- | --- | --- |
| 销售报表 | `reports/sales.vue` | 静态卡片，需要真实指标、筛选、导出 |
| 商品报表 | `reports/products.vue` | 示例数据，需多维分析（渠道、库存、ROI） |
| 转化漏斗 | `reports/conversion.vue`、`customer/analytics/funnel.vue` | 静态漏斗，需自定义阶段、分群、告警 |
| 营销分析 | `market/analytics.vue` | 卡片示例，需活动/渠道 ROI、分群、归因 |
| 客户分析 | `customer/analytics/**` | 漏斗、留存、分群示例，需与旅程、营销联动 |

## 3. 角色与价值
| 角色 | 核心诉求 |
| --- | --- |
| 营销/增长 | 查看活动、渠道、旅程效果、ROI、归因 |
| 产品 | 了解用户行为、功能使用、转化漏斗、实验结果 |
| 运营 | 获取运营报表、转化率、库存周转、售后数据 |
| 管理层 | KPI 看板、目标进度、异常告警 |
| 数据团队 | 定义指标、治理数据、提供 API |

## 4. 功能规划概览
1. **指标与看板**：指标库、KPI 卡、拖拽式看板、订阅与权限。
2. **漏斗与路径分析**：自定义阶段、过滤条件、分群对比、路径探索。
3. **分群与 cohort**：动态/手动分群、留存分析、LTV、预测。
4. **实验 & A/B**：实验管理、统计显著性、目标指标、版本对比。
5. **归因分析**：活动/渠道/旅程归因模型（首次、末次、线性、算法）。
6. **报表导出与订阅**：定期/实时报告、API、导出、告警。

## 5. 迭代路线
- Phase 1：指标库、看板基础、漏斗、销售/商品报表接入真实数据。
- Phase 2：分群、cohort、实验分析、告警。
- Phase 3：自动化归因、AI 异常检测、自然语言查询。

## 6. 依赖与数据
- 依赖订单、支付、渠道、营销、旅程、库存、财务等数据；需要数据仓库/实时流、数据治理、权限管理。
