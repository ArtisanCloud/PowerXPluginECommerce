# 实验 & A/B 测试 PRD

> 面向旅程/活动/渠道/页面实验，提供实验管理、统计分析、显著性检验、目标指标跟踪。

## 1. 目标
- 支持多种实验（旅程节点、促销方案、渠道文案、价目策略）的配置、运行、分析、决策。

## 2. 信息架构
- 实验列表：名称、类型（旅程/活动/页面/定价）、状态、开始/结束、目标指标、负责人。
- 实验详情：
  - 版本/变体：A/B/N、多臂；曝光、样本、转化。
  - 目标指标：GMV、订单、转化率、留存。
  - 统计：显著性、p-value、置信区间、推荐版本。
  - 日志：实验配置、变更、告警、记事。

## 3. 功能
| 功能 | 描述 |
| --- | --- |
| 实验配置 | 定义实验类型、版本、分流比例、目标、持续时间、指标 |
| 数据收集 | 自动收集实验数据（与旅程、活动、渠道联动） |
| 统计引擎 | 计算显著性、推荐版本；支持频率派/贝叶斯 |
| 多目标 & 重叠 | 支持多指标、互斥实验、防止干扰 |
| 告警 | 发生异常（数据缺失、显著性达到、负向影响）时通知 |
| 决策 & 回滚 | 实验结束后选择版本，支持回滚 |

## 4. 数据 & API
- 表：`experiments`、`experiment_variants`、`experiment_metrics`、`experiment_logs`。
- API：`POST /api/experiments`、`POST /api/experiments/{id}/variants`、`GET /api/experiments/{id}`、`POST /api/experiments/{id}/stop`。

## 5. 权限 & 审计
- 权限：`analytics.experiment.manage`、`analytics.experiment.view`。
- 审计：实验变更、版本发布、决策过程。

## 6. KPI
| 指标 | 目标 |
| --- | --- |
| 实验配置时间 | < 1 小时 |
| 数据延迟 | < 10 分钟 |
| 实验成功率 | ≥ 70% 的实验提供决策价值 |

## 7. Backlog
- 自动实验建议。
- 与旅程画布整合（节点级实验）。
- 多臂老虎机/连续实验。
