# SKU & 变体管理

SKU（库存量单元）管理模块，用于管理具体的商品规格、价格和库存信息。

## 功能特点

- **列表/筛选**：展示所有SKU，支持按规格组合、状态等条件筛选
- **批量导入/导出**：支持SKU数据的批量操作
- **基础信息管理**：维护SKU的基本属性（规格组合、条码等）
- **库存管理**：管理可用库存、安全库存、预警阈值等
- **物流信息**：维护重量、体积、包装尺寸等物流相关属性
- **约束条件**：设置起订量、限购等业务约束

## 页面内分区

### 1. 列表/筛选（规格组合）
- SKU表格展示，包含编码、SPU、规格组合、价格、库存等信息
- 支持按SKU编码、SPU、规格组合等条件筛选
- 支持搜索SKU

### 2. 批量导入/导出
- 批量导入SKU数据
- 批量导出SKU数据
- 支持Excel、CSV等格式

### 3. 基础（规格组合、条码）
- SKU编码（唯一标识）
- 关联SPU
- 规格组合（颜色、尺寸等属性的组合值）
- 条码（UPC/EAN等标准条码）
- 描述信息

### 4. 库存（可用/安全/预警；序列号/批次可选）
- 可用库存数量
- 安全库存阈值
- 库存预警阈值
- 序列号管理（可选）
- 批次号管理（可选）

### 5. 物流（重量、体积、包装尺寸）
- 商品净重
- 商品毛重
- 包装体积
- 包装尺寸（长×宽×高）

### 6. 约束（起订量、限购）
- 最小起订量（MOQ）
- 最大购买限制
- 预售设置
- 限时供应设置

## 使用说明

1. 在SKU列表页面可以查看所有SKU，进行筛选和搜索操作
2. 点击"添加SKU"按钮进入新建SKU流程
3. 通过操作列按钮可以对单个SKU进行查看、编辑、删除操作
4. 使用批量操作按钮可以对选中的SKU进行批量导入/导出
