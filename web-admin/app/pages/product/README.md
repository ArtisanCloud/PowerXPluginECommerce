# 商品中心

商品中心是电商平台的产品管理体系，包含以下模块：

## 1. 类目管理 (/product/categories)
- 主要功能：管理商品分类体系

## 2. SPU管理 (/product/spus)
- 主要功能：管理标准化产品单元(SPU)
- 功能包括：
  - 商品列表（增删改查，状态：草稿/上架/下架）
  - 商品详情（名称、主图/详情图/视频、描述、SEO信息）
  - 类目归属（类目、品牌、标签）
  - 属性模板（类目绑定的属性集）
  - 多语言、多渠道展示配置

## 3. SKU & 变体管理 (/product/skus)
- 主要功能：管理具体的库存单元(SKU)和变体
- 功能包括：
  - 列表/筛选（规格组合）
  - 批量导入/导出
  - 基础（规格组合、条码）
  - 库存（可用/安全/预警；序列号/批次可选）
  - 物流（重量、体积、包装尺寸）
  - 约束（起订量、限购）

## 设计理念

- **类目管理**：专注于商品基础数据结构管理（分类体系）
- **SPU管理**：专注于商品信息内容管理（标准化产品单元）
- **SKU管理**：专注于具体的库存单元和变体管理（价格、库存、物流等）
