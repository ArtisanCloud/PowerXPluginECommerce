# 规则配置功能说明

## 功能概述
本功能实现了推荐/分销系统的规则配置管理，采用策略模式来组织各种规则。

## 核心概念

### 策略（Strategy）
策略是规则的组合体，一个完整的分销策略包含以下6种规则组件：
1. **奖励对象** - 定义谁可以参与分销（如：所有用户、一级分销员、二级分销员等）
2. **奖励内容** - 定义奖励的具体内容（如：积分、现金、优惠券等）
3. **触发条件** - 定义在什么条件下触发奖励（如：注册、首次购买、满额购买等）
4. **分销比例** - 定义不同级别分销员的佣金比例
5. **结算方式** - 定义佣金如何结算（实时、日结、周结等）
6. **提现规则** - 定义提现的条件和规则（最低金额、手续费等）

这些规则组件可以独立创建和管理，然后组合成不同的策略来满足不同的业务需求。

## 规则逻辑说明

### 规则组件的独立性
每种规则组件都是独立创建和管理的实体，可以被多个策略复用。例如：
- "所有用户"这个奖励对象可以同时被"基础分销策略"和"节日促销策略"使用
- "一级分销10%"这个分销比例可以被多个不同的策略引用

### 策略的组合性
策略通过引用各个规则组件的ID来组合成一个完整的分销规则。一个策略的完整逻辑流程如下：

1. **奖励对象筛选**：确定哪些用户可以参与此策略
2. **触发条件判断**：当用户满足触发条件时（如完成注册、下单等）
3. **奖励内容发放**：按照设定的奖励内容给予用户奖励
4. **分销比例计算**：根据用户的分销级别计算佣金比例
5. **结算方式执行**：按照设定的结算方式处理佣金结算
6. **提现规则限制**：用户提现时需要满足设定的提现规则

### 实际应用举例

#### 基础分销策略
```
规则组件：
- 奖励对象：所有注册用户
- 奖励内容：现金10元
- 触发条件：完成注册
- 分销比例：一级10%，二级5%
- 结算方式：实时结算
- 提现规则：最低提现100元，无手续费

执行逻辑：
1. 用户A注册成为分销员
2. 系统立即奖励A现金10元
3. 当A邀请用户B注册并购买商品时
4. A获得订单金额10%的佣金，实时结算到账户
5. B邀请用户C注册并购买商品时
6. B获得订单金额5%的佣金，实时结算到账户
7. A、B提现时需满足最低100元要求，无手续费
```

#### 高级分销策略
```
规则组件：
- 奖励对象：一级分销员
- 奖励内容：现金20元 + 100积分
- 触发条件：首次购买满100元
- 分销比例：一级15%，二级8%
- 结算方式：日结
- 提现规则：最低提现50元，1%手续费

执行逻辑：
1. 只有一级分销员可以参与此策略
2. 当被邀请用户首次购买满100元时
3. 邀请人获得现金20元 + 100积分奖励
4. 佣金按照15%/8%的比例计算
5. 佣金每日结算一次
6. 提现时最低50元，收取1%手续费
```

## 页面结构
- `/customer/affiliates/rules` - 规则配置主页面

## 功能特性
1. **策略管理**：创建、编辑、启用/禁用分销策略
2. **规则组件管理**：独立管理各种规则组件
3. **组合配置**：通过策略将各种规则组件组合使用
4. **搜索筛选**：支持按名称搜索策略
5. **分页支持**：支持分页浏览大量策略
6. **状态管理**：支持启用/禁用策略和规则组件

## 使用流程
1. 首先创建各种规则组件（奖励对象、奖励内容、触发条件等）
2. 然后创建策略，将需要的规则组件组合到策略中
3. 启用策略使其生效
