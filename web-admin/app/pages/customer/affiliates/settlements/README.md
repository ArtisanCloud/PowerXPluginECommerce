# 佣金结算功能说明

## 功能概述
本功能实现了分销系统的佣金结算管理，包括：
1. 佣金结算状态管理（待结算、已结算、可提现）
2. 提现申请审核（待审核、已通过、已拒绝）

## 页面结构
- `/customer/affiliates/settlements` - 佣金结算主页面
- `/customer/affiliates/settlements/review` - 提现申请审核页面

## 功能特性
1. 分页支持：所有列表页面都支持分页功能
2. 模态框详情：点击"查看"按钮可查看详细信息
3. 搜索筛选：支持按分销员信息搜索
4. 统计卡片：显示关键业务指标
5. 操作按钮：支持直接在列表中进行操作

## 组件
- `ViewCommissionModal.vue` - 佣金详情模态框
- `ViewWithdrawalModal.vue` - 提现申请详情模态框

## 菜单配置
菜单项已添加到"推荐/分销"子菜单中：
- 佣金结算
- 提现申请审核
