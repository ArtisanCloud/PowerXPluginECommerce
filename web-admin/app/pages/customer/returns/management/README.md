# 退换货申请管理功能说明

## 功能概述
本功能用于管理客户的退换货申请，包括待审核、处理中、已完成三个状态的申请管理，支持审核和拒绝操作。

## 核心功能

### 1. 待审核
- 显示所有待审核的退换货申请
- 支持查看申请详情
- 支持通过或拒绝申请
- 支持搜索和分页

### 2. 处理中
- 显示所有正在处理的退换货申请
- 显示处理进度
- 支持查看申请详情
- 支持搜索和分页

### 3. 已完成
- 显示所有已完成的退换货申请
- 显示处理结果（已批准/已拒绝）
- 支持查看申请详情和处理记录
- 支持搜索和分页

## 页面结构
- `/customer/returns/management` - 退换货申请管理页面

## 功能特性
1. **标签页导航** - 使用标签页组织不同状态的申请
2. **表格展示** - 使用表格展示申请列表，支持分页和搜索
3. **详情查看** - 支持查看申请详细信息，包括客户信息、商品信息、申请详情等
4. **审核操作** - 支持通过或拒绝待审核的申请
5. **进度跟踪** - 显示处理中申请的进度
6. **处理记录** - 显示已完成申请的处理记录
7. **照片查看** - 支持查看申请上传的相关照片
8. **统计展示** - 显示各状态申请的数量统计

## 使用流程
1. 进入"待审核"标签页查看待处理的申请
2. 点击"查看"了解申请详情
3. 根据情况选择"通过"或"拒绝"操作
4. 在"处理中"标签页跟踪申请处理进度
5. 在"已完成"标签页查看处理结果和记录
