# RMA 入口配置功能说明

## 功能概述
本功能用于配置客户自助退换货门户的入口设置，包括申请表单字段配置和退换货类型配置。

## 核心功能

### 1. 全局配置
- **RMA入口状态** - 控制客户是否可以访问自助退换货门户
- **申请时间限制** - 设置订单完成后多少天内可以申请退换货
- **说明文本** - 在申请表单顶部显示的说明文本

### 2. 表单字段配置
支持配置退换货申请表单的各个字段：
- **退换货原因** - 下拉选择字段，预设常见原因选项
- **问题描述** - 多行文本输入，用于详细描述问题
- **照片上传** - 文件上传字段，支持上传相关照片
- **SKU信息** - 文本输入字段，用于输入商品SKU编号

每个字段支持以下配置：
- 字段标签和描述
- 字段类型（文本、多行文本、下拉选择、单选框、复选框、文件上传等）
- 是否必填
- 是否启用
- 选项值（针对下拉选择和单选框类型）

### 3. 退换货类型配置
支持配置三种退换货类型：
- **退货** - 申请退货退款，需要退货和照片
- **换货** - 申请更换商品，需要退货和照片
- **维修** - 申请商品维修，不需要退货但需要照片

每种类型支持以下配置：
- 类型名称和代码
- 类型描述
- 是否需要退货
- 是否需要照片
- 是否启用

## 页面结构
- `/customer/returns/config` - RMA入口配置页面

## 功能特性
1. **标签页导航** - 使用标签页组织不同类型的配置，避免页面过长
2. **表格展示** - 使用表格展示字段和类型列表，支持分页和搜索
3. **模态框编辑** - 使用模态框进行字段和类型的添加/编辑操作
4. **搜索筛选** - 支持按名称搜索字段和类型
5. **分页支持** - 支持分页浏览大量字段和类型
6. **实时验证** - 表单提交前进行数据验证
7. **响应式设计** - 支持不同屏幕尺寸和深色模式

## 使用流程
1. 选择配置类型（全局配置、表单字段、退换货类型）
2. 配置相应的内容
3. 保存配置使设置生效
