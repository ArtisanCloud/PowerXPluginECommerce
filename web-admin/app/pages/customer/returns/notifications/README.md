# 客户通知

客户通知功能用于管理退换货相关的客户通知和提醒，主要包括审核结果提醒和退款进度提醒。

## 功能特点

- **审核结果提醒**：当退换货申请审核状态发生变化时，自动发送通知给客户
- **退款进度提醒**：当退款状态更新时，及时通知客户退款进度
- **多渠道通知**：支持站内信、短信、邮件等多种通知方式
- **模板自定义**：可自定义通知模板内容，支持变量替换
- **状态跟踪**：跟踪通知发送状态，确保客户及时收到重要信息

## 主要功能模块

### 1. 全局配置
- 通知功能开关控制
- 通知发送方式配置（站内信、短信、邮件等）
- 通知模板管理

### 2. 审核结果提醒
- 查看所有审核结果提醒记录
- 手动发送审核结果通知
- 跟踪通知发送状态

### 3. 退款进度提醒
- 查看所有退款进度提醒记录
- 手动发送退款进度通知
- 跟踪通知发送状态

## 使用说明

1. 在"全局配置"中设置通知功能状态和发送方式
2. 编辑通知模板，自定义通知内容
3. 在"审核结果提醒"和"退款进度提醒"标签页中查看和管理通知记录
4. 对于未发送的通知，可手动点击"发送"按钮进行发送
