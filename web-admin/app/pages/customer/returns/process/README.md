# RMA 流程配置功能说明

## 功能概述
本功能用于配置退换货流程的规则和地址信息，包括审核规则、退货地址和物流规则的配置。

## 核心功能

### 1. 审核规则配置
- **7天无理由退货**：支持7天内无理由退货
- **商品类目规则**：针对不同商品类目设置不同的退货规则
- **退货期限设置**：自定义退货期限（天数）
- **无理由退货支持**：配置是否支持无理由退货
- **规则启用/禁用**：控制规则是否生效

### 2. 退货地址配置
- **多地址管理**：支持配置多个退货地址
- **地区匹配**：根据客户所在地区自动匹配退货地址
- **联系信息**：配置退货地址的联系人和电话
- **详细地址**：配置完整的退货地址信息
- **地址启用/禁用**：控制地址是否可用

### 3. 退货物流规则配置
- **承运商选择**：选择退货使用的物流公司
- **运费承担**：配置运费由客户还是商家承担
- **追踪要求**：设置是否需要物流追踪
- **规则描述**：添加物流规则的详细说明
- **规则启用/禁用**：控制规则是否生效

## 页面结构
- `/customer/returns/process` - RMA流程配置页面

## 功能特性
1. **标签页导航** - 使用标签页组织不同类型的配置
2. **卡片展示** - 使用卡片展示配置项，清晰直观
3. **模态框编辑** - 使用模态框进行添加/编辑操作
4. **实时验证** - 表单提交前进行数据验证
5. **响应式设计** - 支持不同屏幕尺寸和深色模式
6. **全局设置** - 支持流程状态控制和默认地址设置

## 使用流程
1. 配置审核规则，设置退货期限和无理由退货政策
2. 配置退货地址，为不同地区设置合适的退货地址
3. 配置物流规则，选择承运商和运费承担方
4. 设置全局配置，控制流程状态和默认选项
5. 保存配置使设置生效
